# 单张卡牌揭晓布局修复

旧样式仍给 draw-result 分配左卡牌右寄语双栏，但寄语已变成按钮，导致卡牌偏左、按钮拉宽。改为单张卡牌居中纵排：揭晓标题、卡牌、寄语按钮、收入卡册。按钮使用浅字深底，提高遮罩上的可读性。卡牌随窗口高度缩放，解锁多张卡牌保留双列。

使用 app.js 中实际 drawResultHtml / prototypeFaceHtml 渲染只读样稿，桌面 1440×1000 与手机 390×844 检查卡牌及收卡按钮边界，截图保存在 output/refinement/card-reveal-centered-20261012.png。临时验证页面已删除。未调用抽卡接口，未修改学习记录或收藏。
