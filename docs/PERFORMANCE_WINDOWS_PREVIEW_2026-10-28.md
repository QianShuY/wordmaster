## 本次改动

1. Boss 页面实际显示 WebP，却预载了五张旧 PNG，合计 13,442,775 字节。现在预载与显示使用同一份 WebP，仍提前准备三种技能姿态，避免首次放招时才加载。
2. 旅行入口与地图共用同一份 WebP；配乐试听场景也不再请求原 PNG。
3. 八张场景/角色 WebP 重新编码，合计从 16,221,278 降到 5,064,450 字节，减少约 68.8%。图片像素尺寸保持，透明通道逐像素一致；使用高质量有损编码，不宣称像素完全无损。原始 PNG 仍在源码仓库，可继续编辑。逐张尺寸、源哈希、编码参数和误差指标见 [编码记录](ADVENTURE_IMAGE_ENCODING_2026-10-28.json)。
4. 地图新增只读 `todayPlan` 展示投影，显示与今日页相同的均衡任务数量，包括第一次进入学习前。已保存的任务、旧记录通关规则、遗忘曲线与判分继续沿用；读取投影不冻结任务、不推进关卡。兼容旧服务时回退原计数。
5. Windows 打包时只排除已有 WebP 且没有 HTML/CSS/JS 引用的对应源 PNG；源仓库保留全部原图。清单明确记录省略项及每个发行文件的哈希。
6. API 测量脚本改用实际测量日期生成输出，补充旅行词池、成长记录接口，并记录实际显示的 WebP 体积；可用 `WORDMASTER_MEASURE_DATE` 明确指定客户端日期。

## 性能观测及限制

本轮正式服务最初未运行。测试服务使用 SQLite 在线备份产生的隔离副本，未重置或写入原始学习库。

本地 API 热请求多数约 15–17 ms，词库总览约 53 ms；这些数字包括本地 HTTP 调度，不等同 SQL 自身耗时。本轮没有针对这些接口宣称查询性能提升，也没有增加可能过期的学习结果缓存。

在独立端口的实际页面中，诊断脚本通过浏览器自身 PerformanceObserver、资源计时和 180 帧采样，将结果写入诊断 DOM 面板，随后由浏览器工具读取。诊断脚本不进入发行包。

战斗该次资源传输减少约 82.8%，修改后已无对应 PNG 请求，也无素材加载错误。资源传输样本受已有缓存影响，表中时间仅是这台机器的单次观察，不能当作严格冷启动 A/B 或普遍提速保证。

首页最初首屏绘制约 88 ms；地图和战斗短样本帧间隔 P95 约 6.2–8.1 ms，部分样本各有一次超过 50 ms 的间隔。没有把短采样推断成长期帧率/低配置设备保证。地图在 1280×720 中仍为约 797×531，页面总高 720；没有缩小画面来换取数字。

本地原始结果：`output/refinement/browser-*-20261028.json`、`api-baseline-20261028.json`。API 样本是在最后补齐地图展示字段前采集；最终包另做了页面与规则验证。

## 使用及升级

新安装：解压完整 ZIP 后双击 `WordMaster.exe`。不要只复制一个 EXE；运行时和页面文件都在同一目录。

现有安装：正常关闭旧服务后更新程序文件，保留原来的 `data/`。解压到全新目录直接启动会建立新的空白个人数据库，不会自动读取另一个目录的学习记录。不要用预览包覆盖或删除原数据库。

本轮源码中的更新也可通过原项目目录的启动器加载，无需迁移学习库。此次没有替用户重启或强停原服务；测试只启动、停止本轮自己创建的隔离服务。
