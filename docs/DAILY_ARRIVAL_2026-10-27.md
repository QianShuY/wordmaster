# 每日抵达：让学习成为一段真实旅程

## 本次行为

- 沿用原有每日计划与服务端通关校验，不增加学习量。学习页收到首次通关成功响应后，提供“看看今天抵达的地方”；进入地图播放对应的短行路演出。地图内手动通过当天关卡也使用同一流程。
- 旅人沿实际绘制的道路移动约 2.9 秒，第一程约 1.9 秒。脚下路线点亮，下一小段迷雾逐渐展开；地图尺寸和页面布局保持稳定。
- 抵达后，右栏暂时换成当日手账：地点画面、抵达短句、真实通关日期与随行词库、明日方向。第一程到第十三程分别有地点对应的收尾文字；第十四关继续走正式 Boss 与章节结局流程。
- 只有第 2、5、8、11、13 程会出现对应的新线索，可展开阅读。通关后仍可在地图及拾笺目录回看；没有为每日抵达额外发奖。
- 可跳过行路、按 Escape 收起或直接切换导航。减少动态、手动停风或隐藏页面时直接呈现抵达内容；离开页面清理动画，迟到的回调不会覆盖新选择。
- 路线预演增加“体验抵达演出”，演出手账明确标注预演，不写学习、旅程、奖励或真实抵达已读状态。

## 首次展示与恢复

共享客户端模块 `shared/campaign-arrival.js` 保存一个同源当前标签页的待展示标记。地图须从服务端读到完整连续的实际旅程，且待展示关卡是今天刚保存的最后一程，才生成抵达手账。仅打开既有存档、传入未通过关卡、旧日期或过期标记均不自动播放。

演出开始前，展示凭据按实际旅程历史记为已读，并消费待展示标记。刷新、关闭中断和重复完成响应不会反复播放。浏览器存储不可用时安全退化，不阻断学习；本机制不代替服务端通关存档，也不提供跨浏览器展示状态同步。

若通关写入成功但地图数据暂时读不到，待展示标记留待下一次成功读取。不会因演出失败回滚或重复提交已经保存的通关结果。

## 体验入口

地图左侧“路线预演” → 调整到想看的已完成关数 → “体验抵达演出”。正式流程无需预演，完成当天计划后从学习完成页进入即可。
