# 新词巩固完成判定与恢复步骤

用户反馈刚学完又被安排整批词义复习。只读记录核对发现七词均为：词义已通过，拼写一次错误后一次正确，服务端回忆仍未完成。错误根源是新词前端强化在一次错误后只需一次正确，服务端需要两次正确；前端已经显示完成，服务端随后又将未完成词排入词义回忆。

## 修复

- 新词 choice/spelling 与旧词 review/review-spelling 全部服从服务端返回的错误次数与连续正确次数，防止提前增加完成数和移除重测队列。
- 从未完成回忆恢复时，仅补缺少的步骤；词义已通过则直接进入拼写，不整批重做词义。普通到期复习的上一轮 complete=true 不视为本轮已通过。
- 对旧客户端产生的“词义已完成、仍被缓存为 review”的断点，在刷新词页内容后转换为拼写强化，保留词条和已保存学习记录。未提交的输入不作伪造恢复，不修改数据库来代替作答。
- 首页将此状态显示为“待完成拼写”，明确词义已通过；词义通过但拼写未完成不再计作已完成复习词。
- 部分词先通过拼写、另一些先通过词义时，记录原本可跳过的拼写身份，防止词义补齐后因服务端 complete 状态变化而要求已通过步骤再做一遍。

## 验证

完整自动回归 165 项通过，日志 output/refinement/tests-20261017-consolidation-consistency.txt。新增/扩展测试覆盖新词和旧词四个阶段的一次拼写错误后需第二次正确、恢复时跳过已通过词义、未来到期正常复习不被跳过、复习完成数不提前增加。

独立浏览器与临时数据库夹具，构造旧 review 断点和“词义已过、拼写错误一次后正确一次”状态。首页实际显示“待完成拼写”，点继续直接进入拼写；再次拼对并收到完成响应后断点被清除。此浏览器作答响应为受控夹具，服务端真实状态变化由隔离 API 回归验证；没有代答用户词条。测试服务和浏览器均已关闭。
