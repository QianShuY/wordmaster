## 1. 审核结论与目标

当前卡面在桌面约 69% 为插画、31% 为纸色信息栏；手机上约 60% 为插画、40% 为信息栏。标题、稀有度、说明和收藏状态同时挤在卡面，使插画的收藏价值被削弱。N/R/SR/UR 主要依靠边框颜色和小徽标，整页浏览时高级卡不够有辨识度。

返工目标：**卡册远看先看到画；近看才读到故事。** 画面承担吸引力，文案承担科普和轻度鼓励，稀有度承担收藏惊喜。避免把字缩得难读来换取画面面积。

## 2. 卡面信息层级

### 卡册列表正面

- 维持 5:7 左右的卡牌比例，插画可见面积目标 **≥85%**。用全幅插画或接近全幅的画框，不再保留占 31%/40% 的独立白色信息栏。
- 卡面只保留：标题（最多两行）、小型稀有度标记；分类可做左上角极小标签。底部用高度受控的半透明渐变或纸墨遮罩保证标题清晰，覆盖范围尽量控制在下方 12–18%。
- 科普段落、鼓励句、获得日期、解锁说明放进详情视图。卡册网格上不要再放“已收入卡册”这类重复状态；已获得由原画呈现，未获得由锁定态呈现。
- 所有类别遵循同一文字位置和对齐规则；不能为了长标题把整张卡的画面压小。长标题最多两行，详情里完整显示。
- 给每张插画可选焦点位置（如 `object-position` 或元数据 focal point），使不同构图的主体在 190px 卡宽与 160px 手机卡宽都不被裁掉。

### 详情与抽卡揭晓

- 点开卡片后展示较大的完整插画，并在旁边或下方显示标题、稀有度、一个可核查的知识点、与画面相关的温和鼓励，以及来源或“灵感札记”。手机详情可纵向滚动，但首屏必须先看到画。
- 抽卡揭晓先给画面和稀有度，再给文字。隐藏卡同时出现时保证“收入卡册”按钮始终可见或容易滚到。
- 未拥有卡仍不展示完整图和名称；隐藏卡不得泄露解锁前内容。保持现有 62 个卡牌 ID 与收藏记录。

## 3. 稀有度视觉语言

| 等级 | 静态外观 | 交互或揭晓 | 约束 |
|---|---|---|---|
| N 普通 | 克制纸边/墨色细线，画面原色 | 轻微抬起 | 用安静衬托高级卡，不要整体灰掉插画 |
| R 稀有 | 暖金或朱砂的细微金属感，角标更精致 | 鼠标/触摸时一次短暂侧光 | 不用大面积红色边框替代质感 |
| SR 史诗 | **透明衍射光栅**：薄彩虹细纹只浮在边缘或画面的高光区域，静止截图仍可感知 | 指针位置缓慢改变反射方向，翻卡时掠过一次 | 不遮住主体，也不让全图变白、变灰或变彩虹滤镜 |
| UR 传说 | 更细致的棱镜光、局部金箔和有层次的透明光栅；与 SR 明显不同 | 详情/抽卡允许一次完整揭晓动效 | 卡册列表静止时也应认得出 UR；同屏不让多张卡持续播放 |

实现建议：用低透明度 `repeating-linear-gradient`、局部 `mask`、混合模式和边缘高光叠层做光栅；通过 CSS 自定义变量改变反射位置，指针更新用 `requestAnimationFrame` 限频。透明效果应叠在**画面上方但文字下方**，`pointer-events: none`。移动设备无悬停时保留好看的静态光栅，可在打开详情时触发一次短动画。减少动态效果模式下保留静态稀有度差异。

## 4. 卡牌文案：知识与鼓励分层

每张卡建议有 3 个独立字段，按卡牌稳定 key（现有 `palette`）维护内容，避免直接把全部文字挤进卡面：

1. **封面短句**：可选，建议 8–16 个汉字；只在大图揭晓或详情出现，卡册小卡默认不显示。
2. **知识点**：一到两句、具体、可核查。历史/科学/自然类记录来源链接；不确定的说法改成“可能”“常被认为”等准确语气，不编精确数字。
3. **鼓励句**：与画面意象和学习过程自然相连，像收藏卡寄语，不像打卡催促。避免“必须坚持”“再不背就落后”、重复的鸡汤句和对用户成绩的臆测。

虚构、游戏感、纯风景类卡若没有合适事实，用“灵感札记/观察”明确标识，不把想象写成科普。建议以独立 JSON 内容文件按 `palette` 映射，这轮不必为了文案改动用户 SQLite；实现 agent 可提出更稳妥的结构，但必须保留 ID 和已拥有卡。

**示例：冰岛极光**

- 卡册正面：`冰岛极光` + `SR`，不显示整段说明。
- 详情知识点：`极光的光，来自高层大气中的气体受带电粒子激发。` 来源：[NASA Science: Auroras](https://science.nasa.gov/sun/auroras/)。
- 详情寄语：`看不见的积累，也会在某一天发光。`

**示例：存档点**

- 详情标记：`灵感札记`。
- 寄语：`今天没记住的词，明天还可以从这里再出发。`

先为 4 张代表卡写完整文案（N、R、SR、UR 各一），让我审核语言风格后再批量处理 62 张。批量阶段需逐条检查重复句式、事实来源和中文自然度。

## 5. 可选动态卡面资源

用户愿意另找生成模型制作动态画面；这部分先作为 **C2 可选增强**，不阻挡静态卡面返工。优先只试 1–2 张 UR/隐藏卡，确认观感与体积再扩展。

- 输入给视频模型：当前原创静态卡图。要求保持人物、物体、构图和色彩一致，只让画面中的光、云、水、星尘等局部缓慢变化；镜头锁定；无新增角色、文字、标志；首尾自然衔接，适合作为 5–8 秒静音循环。
- 交付：原 WebP 继续做静态封面和加载失败回退；每张动态卡附本地视频文件、匹配封面画面的 poster，以及生成提示词/来源记录。不要直接依赖第三方视频 URL。
- 网格只显示静态图。仅当用户主动打开详情或抽到该卡时加载视频；关闭详情、离开页面或后台时暂停。支持用户手动暂停/重播；减少动态效果时只显示静态 poster。
- 如果使用 HTML `<video>`，跨 iOS/Safari 的静音内联播放需实测 `muted`、`playsinline`；用 `preload="none"` 控制非当前卡的下载。视频是否自动播放以真实设备结果为准。
- 不预设 62 张都要动态化；动效资源的格式、大小和数量以首批样卡在手机与 Mac 的性能结果决定。

动态资源的生成提示词模板：

> Animate this original portrait card illustration while preserving the exact composition, subjects, palette, and painterly texture. Locked camera. Only subtle localized motion in [light/cloud/water/particles]. Seamless 5–8 second loop. No new objects, no character redesign, no camera pan or zoom, no text, no logo, no flashing. First and last frames should match naturally.

## 6. 交付顺序与验收

**先交 4 张视觉样卡，再全量铺开。** 样卡必须覆盖 N/R/SR/UR，给同一桌面网格和 360px 手机双列截图，以及四张详情图、SR/UR 交互录屏、减少动态效果截图。样卡视觉通过后才批量应用 62 张与全文案。

审核要点：

- 插画在桌面和手机列表中均是绝对主角，实际可见面积 ≥85%；标题清楚、画面主体无遮挡。
- 不看小字也能分辨 N/R/SR/UR；SR 与 UR 的静态截图有明显但克制的区别。
- 光栅是透明反射层，不覆盖整个画面；深色、浅色插画都可用。若彩虹纹在大部分画面上抢主体，退回修改。
- 文案在详情中读起来像“知识 + 收藏寄语”，有事实来源；不把所有 62 张写成同一套励志模板。
- 360/390/430px、横屏、平板、桌面无溢出；键盘可打开/关闭详情、焦点返回；减少动态效果不损失功能。
- 62 张本地 WebP 与卡牌 ID、已有收藏均保留；无新的公网图片依赖。动态视频缺失或播放失败时静态卡面完整可用。
