## 1. 安全准备

Windows PowerShell，在本地现有的 `wordmaster` 目录中执行：

```powershell
git status --short
git fetch origin
git switch --create wordmaster-desktop-review --track origin/feat/study-data-backup-20261009
node --version
npm ci
npm test
node --check static/app.js
```

如果当前有尚未保存的改动、或者同名测试分支已存在，**不要强制覆盖或 reset**，先整理本地改动，再选择安全的分支切换方式。

要求 Node 22.5+，推荐 Node 22 LTS。**不要先拿生产数据库做删除/编辑测试。** 建议为验收单独设置数据库路径：

```powershell
$env:WORDMASTER_DB_PATH = Join-Path $env:TEMP "wordmaster-desktop-review.db"
npm start
```

这会生成/使用临时测试库（不要覆盖用户原有备份）。浏览器打开 http://127.0.0.1:3456 。如端口已被旧进程占用，先安全关闭旧进程并确认打开的是本轮代码。

## 2. 用户体验与功能验收

### V1.2 重点视觉验收：学习中枢 / 计划工作台

这次最大的改动是电脑端首页，不是再添加一个设置按钮。请把下面四种状态分别截图并检查：

1. **未设目标**：进入「今日」时，主视觉应为宽大的「长期方向」计划卡（左）和「当下任务」行动卡（右）；显示明确的「制定学习计划」，不再需要去词库卡片找小弹窗。主卡显示真实的总词数、剩余新词、已接触覆盖率，不把覆盖率误写成掌握率。
2. **编辑计划**：点击「制定/调整学习计划」后弹出桌面双栏大面板。分别选择两周 / 一个月 / 两个月 / 三个月以及手动日期，右边实时展示日均新词数量、剩余天数和目标结束日期。尝试超紧目标（每日超过 200 词）应明确警告并禁用保存，不能暗自接受达不到的日期。
3. **计划已设定**：保存后回到今日，主卡显示目标日、剩余天数和每日安排；切换词库时计划及当天数字跟着所选词库变化，不同词库的信息不能混淆。取消计划应保留学习记录及复习进度。
4. **全天任务完成或空词库**：主页不能出现还能开始学习却没题的误导。未有单词时入口去词库管理；学完当天任务时开始按钮禁用，并提示可以查看学习成果或切换词库。

视觉检查：1440×900、1280×720、Windows 显示缩放 125%，对比暗绿色右侧行动区、左侧留白和文字可读性，注意模态框不能被窗口底部截断；记录浏览器控制台异常。

Android 独立版仍保留旧「今日」与旧计划弹窗，V1.2 **没有修改任何原生 Android 文件或存储**。

### A. 今日与学习旅程
- 首次启动：今日页显示正常，空数据不会冒出假学习记录。
- 设置学习计划，选一本词库学习，查看等级、真实累计墨点、连续学习天数、7 日答题柱图、10 次作答目标、6 枚印记。
- 做一次默写：第一次答对 +12 墨点；答错后改正 +6 墨点；答错/放弃不加墨点；一轮结束显示本轮墨点。
- 刷新页面后墨点应保留且不重复累计；原有复习日期不应受新增游戏化 UI 影响。
- 达到 10 次作答后，未抽卡显示“可以去卡册抽卡”；领取后显示“今日卡牌已领取”。

### V1.4 必测：学习旅程、退出与恢复

1. 在**临时测试数据库**建立一本 13 个已到期复习、10 个计划新词的词库。首页显示 23 个任务词；点击开始能看到明确的「到期复习 → 新词学习 → 巩固默写」三阶段指示，第一阶段 13 / 13，不能只出现 10 题。
2. 先完成 3 个复习词，点击左上角「保存进度并退出」，返回「今日」应出现绿色断点提示、已完成 3 / 23 和「继续上次学习」按钮；剩余复习显示 10，新词仍为 10。再进入必须从第 4 个未完成复习词继续，不能重复前三个；刷新网页后也应如此。
3. 故意答错一个复习词，再从回炉队列中答对，退出 / 刷新 / 恢复时仍保持回炉判定与答题计数，不能重复得经验值。
4. 完成 13 个复习词时，阶段结算不再只有“再来一轮”，应展示真实的首次答对、回炉答对、错误或放弃次数；下一步按钮明确写着「继续学习新词 · 10 个」。退出在此结算界面，再打开应回到阶段完成界面，而不是重新做 13 个词。
5. 学完 10 个新词，阶段结算显示认识的词数与本轮回看数，下一步为巩固默写。暂停在第 5 个新词并刷新，再恢复不能把前 4 个刚学过的新词塞回到期复习阶段。
6. 默写阶段进度不计入原本 23 个今日任务词的重复数量；默写结束提示真实结果，并能返回今日页。独立「错题回炉」不得误读取今日断点。
7. 次日再次进入时，前一天的断点应自动过期并重新按 SQLite 进度计算当天任务。**不要修改真实电脑日期**，可通过自动单元测试验证同日 / 跨日逻辑。
8. 关闭网页 / 刷新前，要等待「正在保存答案」变成「已保存」或者进入下一题；浏览器磁盘配额不足 / 隐私模式禁止存储时不会自动保存断点，这种条件不能宣称恢复成功。
9. Edge/Chrome 测试键盘输入、翻卡、专注模式、完成页「返回今日」；放大到 125% 看三阶段进度是否挤压词卡。

**本轮验收目标：**真实学习记录继续由 SQLite 管理，浏览器断点只用于恢复页面顺序；不要把 localStorage 当作同步或备份。Android 暂时没有该功能。

### B. 专注背词
- 进入学词/默写/释义模式，点击右上「◉ 专注」，顶部导航和装饰消失，题目仍完整可操作。
- 按 Esc 退出专注，或点击「◉ 退出专注」；退出学习后正常导航恢复。
- 在输入框打字、使用回车、A–D/1–4、查看释义、播放发音时，不发生自动跳页或热键冲突。
- 今日页**不再出现 10/20/40 单轮限制选项**；用独立测试库构造「待复习 13、新词计划 10」后，右侧应直接显示本次完整任务 23 词。点击开始，第一步完整显示 13 词复习，完成后可点“继续今日新词”进入 10 词学习，再可进入刚学新词的默写。不要把 10 误认为总题数。

### C. 大词库管理
- 打开较大的内置词库：默认每页 40 条，能快速进入，无须浏览器渲染全部词。
- 搜索英文、中文释义；用 `%`、`_` 字符检索时只按字面匹配，不将其当作通配符。
- 筛选“尚未学习 / 待复习 / 待回炉错题 / 已掌握”，分页上一页/下一页及结果数量、总页数正确。
- 搜索后迅速连续输入、切换词库、切换其他页面，不出现旧查询覆盖新页面或 JS 报错。
- 编辑、删除、添加、批量导入后结果应更新；搜索结果为空时显示清晰空状态。
- 特别录入含撇号单词 `don't` 和含单引号的自建词库名 `Alice's words`，操作计划、删除、错题移除不能报错。
- 删除词条必须有确认提示；测试时只对临时库操作。

### C2. 学习数据页口径（V1.3 重点）
- 主页选择「六级核心词汇」后进入学习数据，默认统计同一本词库，应能看到与主页一致的待复习 13，而不是其他词库累加成 106。
- 切换到“全部词库”可以看到总待复习量；但每日新词只显示当日实际新学总数，**不能再次展示跨词库配额相加的 0/255**。
- 切换范围时连学天数、今日已作答、已掌握单词、正确率、学习柱图、热力图、困难词全部对应这个范围。
- 正确率的 58 等百分数应使用与 0、106 等同级指标一致的字号，百分号小一号，不得缩小整个数值。

### D. 数据可靠性
- 学习数据页执行“备份学习数据”，下载的 .db 文件要能用 SQLite `PRAGMA integrity_check` 得到 `ok`。
- 下载后继续学习，历史备份不应被新增学习行为改变。
- 不要在程序运行时直接替换真实数据库，不要把个人学习库提交到 GitHub。
- Windows EXE 安装/升级与真实库恢复要后续单独测试，**本轮网页通过不代表 EXE 发布已完成**。

### E. 视觉与性能
- Windows Edge/Chrome，至少核对 1440×900、1280×720，以及浏览器 110% 或 125% 缩放。
- 首页、学习页、错题本、词库管理、卡册及抽卡、统计图、备份入口都要看。
- 检查大字号中文/英文换行、按钮能否点击、悬停提示、加载/错误态、输入焦点、页面纵向/横向滚动。
- 不满意的地方请附浏览器截图（含问题位置），以及具体复现步骤。若能测，记录打开大词库首页与搜索时是否卡顿。
