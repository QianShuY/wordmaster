# 第一章 · 雾桥守卫：形象与动态设计

日期：2026-10-12。依据：旅行与咒语设计草案第 5、9、10 节。

## 本轮交付

原创首章 Boss「雾桥守卫」的正式首版立绘、独立雾桥场景、可交互动作演出页。入口为 `/adventure/boss.html`，今日页收藏陈列下方也有「雾桥那端，守卫已醒」链接。

这是角色与演出的落地，不是第一章可通关游戏。预览不读取或写入学习数据库，不产生步数、生命损失或通关奖励；正式英语题池、地图与战斗结算仍待开发。

## 形象设定

守卫是古老桥关的守信者，持有一封失去文字的信。它由风化石拱、青墨石甲、旧黄铜与象牙色残页组成。空洞面门中保留一束暖火，避免依赖人脸表情传达敌人意图。

- 提灯：预告重击的视觉中心。蓄力时灯火扩大，守卫微向前倾。
- 石印盾：主要轮廓与破盾对象。护盾光环先扩张，随后碎片散开；之后保持破绽状态。
- 残页披风：呼应旅行手账。待机轻浮，胜利时伴随墨雾消散。
- 色彩：深青、墨黑、暖白纸与旧金，和手账式界面衔接；战斗区域保留更深的明暗层次。

## 动作演出与接口

| 状态 | 演出 | 时间与后继 |
| --- | --- | --- |
| 静候 | 微幅呼吸、灯火、护盾、流雾、飘页 | 持续 |
| 蓄力 | 灯火聚拢、前倾、意图文字变化 | 3.2 秒后重击 |
| 重击 | 守卫前冲、墨雾席卷、柔和亮光 | 1 秒后静候 |
| 受击 | 斜向墨光、冲击环、石甲后退震颤 | 1.1 秒后静候 |
| 破盾 | 光环扩张、石印碎片、受击反馈 | 1.5 秒后破绽 |
| 破绽 | 护盾消失，守卫轻微倾斜 | 持续 |
| 消散 | 角色淡出、残页上扬、雾气减弱 | 2.4 秒后雾退 |
| 雾退 | 敌人隐藏，道路显现 | 持续，可重置 |

`boss-motion.js` 是独立的可测试演出状态机。`trigger(name)` 替换当前演出，不留下旧计时器；`pause(true)` 冻结剩余阶段时间；`advance(ms)` 只推进演出，不处理战斗判题或奖励。

页面提供四个动作按钮、暂停/继续与重置。窗口失焦、页面隐藏会自动暂停；Escape 可暂停。CSS 与媒体查询支持减少动态效果，保留敌人意图与状态文字。声音默认不存在。

## 验证

- 自动测试覆盖蓄力必须先于攻击、暂停冻结、替换演出、破绽与雾退的稳定终态、时间跨度及非法输入。
- 浏览器实际触发蓄力、受击、破盾、消散、暂停、继续与重置，检查 CSS 动画名及最终场景状态。
- 1440px 桌面与 390px 窄屏检查，不横向溢出；角色在画面内，窄屏动作按钮为两列。
- 演出页不发起学习或奖励 API 请求，现有学习记录与收藏不变。

## 后续接入边界

正式战斗由服务端验证答案与结算，再驱动这些演出；不把动作按钮变成通关捷径。个人题池至少 10 个合格已学词，未满足时开放营地教学。继续沿用设计草案的单日词条去重旅行步数、独立战斗事件、一次复起及服务端唯一通关奖励。

最终验证：`runtime/node.exe --test` 共 66 项通过。桌面截图为 `output/refinement/mist-warden-desktop-20261012.png`，窄屏截图为 `output/refinement/mist-warden-mobile-20261012.png`。浏览器测试已验证消散终态角色 opacity=0、破盾实际动画 shield-break、受击实际动画 spell，以及暂停状态下的 animation-play-state=paused。

## 三技能演出强化（2026-10-12）

按本轮确认，守卫从单招扩为三种可分别预览的技能：

- 提灯扫雾：3.2 秒举灯预告 → 1 秒横扫，使用独立前冲姿态、扇形光浪、桥面短促震动；词义辨识用于格挡。
- 石印封路：2.2 秒举盾预告 → 1.2 秒砸地 → 持续封印，使用独立蹲伏盾击姿态、地面墨印与碎石；可通过现有石印碎裂按钮演示破解，正式规则为默写破印。
- 残页风暴：2.6 秒起势 → 3.6 秒风暴，使用独立张开披风姿态、悬浮、旋涡与加速纸页。标明是半血阶段招式预演；正式双词打断判题仍待战斗接入。

新增三张内置 image_gen 生成的独立透明素材，保留同一角色身份：

- `static/adventure/assets/warden-lantern-v1.png`
- `static/adventure/assets/warden-shield-v1.png`
- `static/adventure/assets/warden-storm-v1.png`

最终完整提示词：`static/adventure/assets/skill-generation-prompts.json`。早期动作拼图 `mist-warden-poses-v1.png` 仅保留为设计草图，因相邻轮廓串入裁切区，已不被页面使用。三张独立图解决了该问题，未使用脚本抠图或改画。

暂停同步冻结动作与阶段；新技能替换旧阶段不会产生迟到的攻击。修复低帧率时因限制每帧时间而导致演出状态落后于动画的问题；舞台使用 overflow:clip，避免暂停按钮聚焦时在舞台内部发生滚动。减少动态效果仍提供静态意图与招式形象。

验证：67 项完整测试通过；浏览器确认三招各自加载正确独立图，风暴进入实际旋涡阶段，暂停后动画为 paused；390px 宽度文档 375px 无横向溢出、动作按钮两列。效果截图：`output/refinement/warden-three-skills-20261012.png`。当前仍是动作预览，不写入学习、战斗或奖励数据。

## 石印封路质感重做（2026-10-12）

本轮按用户反馈只集中精修盾击。移除地面圆环 DOM、发光闪屏与盾击时的规则多边形碎片，替换为独立生成的手绘墨裂/碎石透明素材 `static/adventure/assets/shield-ink-impact-v1.png`。内置 image_gen 最终提示词在 `static/adventure/assets/shield-impact-prompt.json`，未用脚本编辑图像。

动作仍使用现有两张立绘，新增约 350ms 的淡出/淡入过渡缓解硬切，并以沉肩、举盾、下砸、触地 144ms 保持与回弹形成连续节奏；这不是逐帧或骨骼动画。触地点不再全屏发光，墨裂沿接触处揭开，低透明度石粉上扬后消失，落地裂痕保留。开始动作会将页面滚回演出区域，减少点按钮后错过演出的问题。

暂停和减少动态效果继续有效；其他两招未按本轮质感方向重制。自动测试 67 项通过。浏览器检查圆环 DOM 数量为 0，盾击结束为 sealed，墨裂透明度 0.72。截图 `output/refinement/shield-ink-study-20261012.png`。
# 提灯与残页质感统一（2026-10-12）

延续石印封路已确认的纸墨方向，替换提灯扫雾的几何光环与残页风暴的旋转圆环。

- 提灯扫雾：收灯蓄势，短暂停顿后扫出不规则暖色笔触；桥面薄雾随灯痕退开，收招时淡回原始站姿。新增手绘 SVG 灯痕 `lantern-brush.svg`。
- 残页风暴：22 张具有破边、字迹与折痕的 SVG 纸页，按固定轨迹聚拢、翻面、爆发和下落。前后层通过亮度、尺寸和阴影区分，末段回到原始站姿。新增 `torn-page.svg`。
- 暂停与失焦继续冻结角色和特效；减少动态模式保留静态灯痕、纸页和文字意图。窄屏粒子场裁切于场景内，390px 检查无页面横向溢出。

仍属于立绘与分层特效的演出预览，未接正式英语施法、生命值、回合或通关结算；不会写入学习记录。动作状态的持续时间与打断规则保持原有约定。

验证：全套 67 项测试通过；浏览器检查三式状态、暂停、素材加载与窄屏布局。
