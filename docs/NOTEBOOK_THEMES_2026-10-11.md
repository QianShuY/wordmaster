# 学习手账与卡牌主题验收

## 功能

电脑端学习页以打开的手账呈现：左页词条与作答，右页陈列插画与语境，页眉显示真实日期和词页编号，页脚词签显示本轮进度。宽屏左右排版，窄屏上下排版。

新词学习显示释义与真实例句；没有例句时保留明确标注的通用伴读短句，不伪造搭配或例句。选择、拼写阶段不把语境内容放入侧页 DOM，单词回看页按原强化规则开放提示。拼写阶段未通过的词签只显示编号，答对后展开英文；结尾收据列出全部本轮词签，待强化词明确标记，印章显示“续”。

已拥有的卡牌详情新增“陈列并使用专属主题”。选定后同步纸色、强调色、背景插画、按钮和学习页景；62 张现有插画各有从图像取色得到的配置，只有已拥有的卡牌可应用。没有显式陈列偏好时沿用经典纸色与已公开的章节封面，不新增未获得插画的曝光。

主题和陈列偏好按数据库身份保存在当前浏览器。刷新与页面切换会恢复；“恢复经典纸色”保留卡牌陈列，仅关闭配色主题；可重新启用陈列主题。刚领取卡牌时会刷新真实拥有状态，预览模式不允许保存陈列或主题。

## 验收

- 自动测试：60 项通过；新增真实词签渲染的答案隐藏验证、拥有状态与恢复经典验证、62 套配色覆盖及可读性验证。
- 62 套纸面主文字对比度 >= 7，辅助文字和主要按钮白字对比度 >= 4.5。
- 独立词库完整走过 5 词认识、选择、拼写，词签与结尾收据均随真实保存推进；刷新后保留学习断点与主题。
- UI 实测图书馆避难所与哥德尔不完备切换，配色和插画不同；恢复经典后刷新仍为经典，再启用恢复选定卡牌。
- 1440×900 桌面、390×844 拼写、360×800 学习排版检查；窄屏横向溢出已修正，页面宽度不超过视口。

## 范围与限制

本轮仅更新本地网页源码，刷新页面生效。没有重打 Windows EXE 或 Android APK。卡牌主题目前共享手账结构，按卡牌插画与配色变化，不代表 62 套独立游戏场景。旅行与咒语、CET6 接入仍待后续开发。


## 首页主题深化

按后续反馈强化主题辨识：背景插画透明度由 0.12 提升至 0.27；首页新增清晰的主题场景横幅，经典模式隐藏横幅。主题标题与寄语随卡牌切换，图书馆、撒哈拉、哥德尔使用专属学习标题，其余复用卡牌已审阅的收藏寄语。长期方向与当下任务加入场景化标题、简短寄语、进度配色和淡场景底图，真实词量、任务状态、日期与学习计划计算不变。

实测图书馆“藏书计划 / 今日书签”及撒哈拉“远行路线 / 今日驿站”；切换和恢复经典时，文字、插画、布局同时更新，测试词库配额始终为 15。390×844 无横向溢出。自动测试增至 61 项通过。截图：output/refinement/theme-home-library.png、theme-home-sahara.png，来自独立验收库。正式库只读检查为 31 条学习进度、48 条作答和 4 张收藏，没有模拟作答或重置。


## 首屏布局修正

按最新反馈移除首页大型白色横幅、单独的场景图片及其右下角标签。主题标题、寄语和日期以紧凑的无框文字叠在背景上，保留卡牌壁纸与场景配色。桌面 1440×900 实测标题区约 136px，计划区域完整落入首屏；390×844 标题区约 117px，页面无横向溢出。截图 output/refinement/compact-theme-home.png 来自隔离验收库。现有主题文案、恢复经典和拼写答案隐藏相关 6 项测试通过；未操作正式学习数据。此项取代上一节的大横幅设计。
