这是 2026-10-15 的只读内容快照。任务尚未分配，不能把模型提交的结果当成审核通过或安装完成。

## 怎么分配

建议先开 3–5 个模型，每个模型先领一个 JSON 文件，拿到结果后由主代理检查质量，再领取下一个。不同模型不能领取相同 task_id。每份最多 100 条，允许模型内部按 20 条核对并持续保存，但最终必须覆盖所领文件全部条目。无需一次把整个目录塞给模型。

| 可交出去的工作 | 输入目录 | 数量 | 适合程度 |
| --- | --- | ---: | --- |
| 四级释义、词性、音标核对和双语例句 | cet4 | 4,460 条 / 45 份 | 重复性高，适合先做 |
| 六级同上 | cet6 | 2,272 条 / 23 份 | 重复性高，适合先做 |
| 考研同上 | npee | 5,384 条 / 54 份 | 重复性高 |
| 专四专八同上 | tem | 12,439 条 / 125 份 | 多义词较多，不确定项必须上报 |
| 待审高考单元的原创教学稿 | gaokao | 2,057 条 / 21 份 | 普通词可做；变体、范围和同形词交主代理判断 |

目录内每份输入的行数和 SHA256 见 manifest.json。排序优先安排缺少例句的词；已有例句仍需核对。四个保留词库合计 24,555 条，不能以只补缺失例句代替全量审核。高考候选中的旧词库释义只是参考，不是可靠答案。

先分配：模型 A → cet4/cet4-001.json；B → cet6/cet6-001.json；C → npee/npee-001.json；D → tem/tem-001.json；E → gaokao/gaokao-001.json。模型数量少就按这个顺序领取。完成后递增编号，登记领取人和状态。

## 直接复制给模型的提示词

你正在为墨词提交词库内容建议。读取指定的一个任务 JSON，以及本 README。只完成该 task_id，不修改输入文件、应用代码、词库源文件或数据库，不运行任何 apply、迁移或构建发布命令。不能代答、抽卡或重置数据。所有结果只写入 docs/model-task-results/<task_id>/；无文件访问能力时返回完整 JSON，不声称已保存。

任务输入：填写你领取的 JSON 的绝对路径。

逐条核对中文释义、词性和音标。为明确选定的一个义项编写自然、简短、原创的英文例句及准确中文译文。已有例句也需核对，不能因已有就跳过。不要把字典例句直接复制回来。不要因另一义项没有用到就删掉它；不充分确定的义项和旧内容保留为疑点。主代理负责批准修订。

以可访问的 Oxford Learner's Dictionaries、Cambridge Dictionary、Collins 等原始词典页面核对；记录具体 URL、所核对的词性和义项。必须真正查看页面，不能靠拼接 URL 声称验证。打不开或无联网能力时标记 needs-review，仍可提供明确标为未经外部核对的草稿。不要绕过验证码，不要虚构引用或人工复核。不能把别的模型当成词典证据。

同形词编号不能合并；bank 银行不能拿河岸例句，bow 鞠躬不能拿弓的例句。英美变体、冠词、短语、斜杠形式、重音随词性变化、不常见用法均不得擅自统一。高考范围、总词数和别名判分政策不要修改；有歧义写入 issues，由主代理处理。

输出 result.json，格式见下面。每条输入必须有一条结果，顺序不变，身份原样保留，不省略疑难条目。再输出 summary.md，列出疑点、建议改动数量和未能核实的项目。所有结果均为 proposal，禁止设置 approved 或 external_human_review=true。

## result.json 格式

```json
{
  "task_id": "cet6-001",
  "input_sha256": "从 manifest.json 复制对应文件哈希",
  "status": "proposal",
  "entries": [
    {
      "identity": { "说明": "保留词库复制 identity 整个对象；高考复制 source_entry、headword、pdf_page、handling、accepted_spellings" },
      "original": { "说明": "保留词库复制 current；高考填 null" },
      "selected_sense": { "pos": "n.", "meaning": "所选义项" },
      "proposed": {
        "pos": "建议词性，未建议改则保持原值",
        "meaning": "建议完整释义，保留已核实的其他义项",
        "phonetic": "所核实词性的英式 IPA，不带外围斜杠",
        "example": "原创英文句子",
        "example_translation": "对应中文译文",
        "teaching_note": "可为空的简短用法提示"
      },
      "evidence": [
        { "url": "实际打开的具体词典页面", "checked_pos": "n.", "checked_sense": "本条义项", "checked_uk_ipa": "实际核对值", "accessed": true }
      ],
      "issues": [],
      "change_reason": "为什么建议改动；不改则说明已核对范围",
      "verification": "source-checked 或 needs-review",
      "external_human_review": false,
      "full_dictionary_senses_reviewed": false
    }
  ]
}
```

模板中的说明占位符必须替换成真实字段。source-checked 只表示列出的证据支持所选义项，不代表整词全部义项正确。建议修改已有例句需说明理由，主代理决定是否替换；不得直接覆盖。

学习和复习调度、错误强化、存档可靠性；Boss 结局和奖励持久化；全站主题、性能与实际界面验收；同形词、词性和内容补丁的合并机制；高考来源与范围判断、旧中考迁移；真实数据保护、回归测试和 Windows 正式发布。
