按本轮确认，词库逐条语言审校改为长期目标，不再阻塞可用功能交付。本轮发布高考学习预览和安全迁移，没有扩大到全部词库的语言重写。

## 已落地

- Windows 默认学习目录为高考、四级、六级、考研、专四专八；全新库共 27,666 条。
- 高考含 3,111 个独立教学单元、3,111 对双语例句。其中 1,054 条保留已有选定义项审稿，2,057 条按用户确认采用待审草稿。3 条音标仍为空，发音按钮继续使用系统朗读。未声称完整词典义项审核或外部人工复核。
- 来源为 3,099 组，拆分后 3,111 单元；原材料声明的 3,100 不作为补删词条的目标，也不将本书标成官方完整考纲。
- 旧中考一律保留为只读历史。原词条 ID、手改内容、计划配置、学习流水、未完成回忆、旅程、收藏以及数据库身份全部保留。新高考独立 ID、初始未掌握、不复制旧学习计划。
- 升级先通过 SQLite 在线备份保存一致副本，再在单一事务中建立新词库和历史绑定。备份失败不迁移；事务检查失败整体回滚。重复启动不会重复建库或生成替换备份。
- 词库详情可查看高考预览说明；旧中考位于「曾经读过的词袋」。高考复用现有每组十词的学习、选择、拼写、复习和旅行入口。拼写变体按词条绑定，不把动词变形、近义词或男女称谓一概判成同一个答案。
