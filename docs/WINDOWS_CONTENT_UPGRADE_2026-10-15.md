# Windows 增量内容升级验收 · 2026-10-15

此前程序只为不存在的内置词库播种数据：升级数据库结构并不会给已有词条补上新释义、音标和例句；运行信息也只返回源码中的内容版本，无法证明数据库已更新。本次补上这条发布路径。

启动时仅处理有来源构建记录、来源哈希匹配且没有同名歧义的活动内置词库。先完成 SQLite 在线备份，再事务更新已核对的字段；不重建词库、不更换词条 ID、不复制熟练度。手改字段、单边自建例句、历史词库和无法确认来源的内容均有保护。独立检查限制可变化的词条字段、构建元数据及身份序列，学习、计划、收藏和其他存档仍须保持一致。

事务内的验证回调现在也受保护指纹检查约束，不能在检查后悄悄修改学习记录。更新失败会回滚内容、保留备份，服务仍可使用原数据；首页提供明确提示与重试。并发重试共享正在执行的任务，成功重开不再备份或重复写入。Android 页面不调用这些桌面接口。

运行信息分别返回实际安装版本和可用内容版本；混合版本或缺失构建记录时，不再用新源码版本冒充已完成升级。接口不会暴露个人数据库或备份的文件路径。
