# 地图后台暂停与词库查询优化

## 本批完成

- 地图页面隐藏、离开或系统启用“减少动态”时，炊烟、水面、大雁、山雾等 CSS 和 SVG 动画统一暂停。页面恢复后仍尊重用户“停风”状态。
- 浏览器验收发现原按钮监听之间的微任务可能先于另一个监听更新状态，已改为更新按钮状态后显式发送地图动态变更事件，避免水面与其他动画暂停不同步。
- 分页、错词列表等读取学习诊断时，改为每 200 个词一批查询进度、错误分布和回忆周期，不再逐词重复查询。单词作答接口仍返回同一诊断结构。
- schema 11 增加词库显示顺序索引，以及错误流水的按词局部索引。迁移只加索引，不改词条、学习计划或学习记录。
- 包含式搜索保留按词库扫描路径，不强迫使用新增排序索引；仍支持中文、英文与百分号等字面字符搜索。

## 对照测量

正式数据库只读 SQL，10 次预热后取 101 次查询中位数，书库为 12,439 词的专四专八。分页与搜索使用和接口一致的完整行 SELECT、LEFT JOIN、排序、LIMIT；测试页为首页 40 条，搜索词为 read。

| 查询 | 修改前 | 修改后 | 说明 |
| --- | ---: | ---: | --- |
| 最大词库第一页 | 2.8528ms | 0.1049ms | 新索引消除分页临时排序 |
| 包含式搜索 read | 4.8170ms | 5.1897ms | 同一扫描路径，未见稳定提速，不宣称改善 |
| 单词错误统计 | 0.0127ms | 0.0107ms | 查询计划由全流水扫描改为按词错误索引；现有流水较少 |

以上只表示数据库温查询。不是浏览器首屏、网络整体响应、动画帧率或 Windows 发行包指标。包含式搜索还需要扫描词库，本批未引入全文搜索。

原始对照：`output/refinement/query-performance-before-20261013.json` 和 `query-performance-after-20261013.json`，脚本 `measure-query-performance.js`。前后查询返回的词条 ID 顺序与错误统计相同。

## 验证

- 全量测试 95 项通过；随后搜索路径修正通过词库分页回归，暂停事件修正通过地图暂停回归。
- 批量诊断测试覆盖 401 个已学词、跨 200 词批次、重复 ID、缺失词、传统错误总数、词义和拼写错误并列、未完成回忆周期；与原逐词算法一致，仅需 9 次查询。
- 地图测试覆盖隐藏/显示、离开/返回、手动停风、系统减少动态。浏览器验证“停风”后烟雾、大雁、山雾均为 paused，统一标记为 true；“起风”后均为 running，标记恢复 false。未捕获控制台错误。
- 本地服务已加载新版；schema 11，所有受保护表行哈希与原先一致，完整性 ok、外键检查无异常。
