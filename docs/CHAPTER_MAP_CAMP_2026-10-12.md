# 雾桥来信 · 地图与营地样稿

本轮实现可点击的插画地图和营地练习，入口为 `/adventure/journey.html`、`/adventure/camp.html`。今日手账的旅行入口改为展开地图，地图、营地、守卫动作手记与英语战斗可相互导航。

## 插画

使用内置 image_gen 工具生成并保存到项目：

- `static/adventure/assets/mist-letter-map-v1.png`：旧纸地图、旧邮亭、芦苇浅湾、渡火营地、雾桥关隘。四个地点用 HTML 路标叠加，未把文字烘焙进图片。
- `static/adventure/assets/river-camp-v1.png`：旧石拱下的帆布帐篷、暖灯、炉火、词袋和空白手账。
- 完整生成提示：`static/adventure/assets/journey-generation-prompts.json`。

地图按实际插画中的地标位置布置路标；点击地点更新札记、路线导航和 URL 查询参数，刷新仍可回到所选地点。按钮具有文字和键盘焦点，无需只凭颜色识别。

## 营地

- 咒语手记：先看已学词与释义，再合上词袋练习默写或词义辨识。
- 本场错词：读取当前数据库实例对应的战斗检查点，并通过战斗引擎验证词池与存档后提供练习。
- 复起宣言：看过教学后隐藏英文，正确回忆固定短句可记为营地已教学；进入战斗营地时可直接出发，无需重复抄写。
- 只读获取实际已学词，不调用日常学习保存接口。营地教学标记保存在按数据库实例隔离的浏览器本地存储，不产生 XP、旅行步数、抽卡或通关奖励。

## 当前范围
