# 桌面英语训练接入

用户选择：统一入口，并打通训练生词。接入对象为 D:/cet6-practice，电脑端优先，手机暂停。

沿用训练仓库 WORDMASTER_INTEGRATION.md 的接入约定：将独立 React/Vite 构建挂在墨词 Express 的 /practice/，同窗口、同来源使用。墨词主导航增加「英语训练」，训练页保留返回墨词与当前栏目导航，直接跟随同来源主题。相较仅跨端口跳转，这一方案不依赖第二个开发服务器；相较合并判题和词库实现，保留既有训练逻辑，降低回归范围。

训练中的单词可主动收进墨词「训练生词」自建词袋；原生词本也可批量收取。WordMaster 服务负责校验、去重、事务与来源记录，不覆盖已编辑词条，不迁移训练里的已掌握标记，也不自动创建 progress、复习期限或插入当前计划。训练仍保存自己的试卷作答、草稿和历史记录。

旧独立端口的浏览器记录不能凭空出现在新来源。训练页明确提示通过已有 JSON 导出/导入迁移，同名记录替换保留确认；旧地址及原记录不删除。不声称训练成绩已经并入墨词的背词统计。

所有开发验证使用隔离数据库。验收范围：主导航进入并返回、真实试卷加载、听力及作文图片在 /practice/ 正常读取、主题非固定端口、收取生词可在墨词词袋查看、重复收取不重复且不改变熟练度、旧备份可导入。
