# 软件内 BT 下载与自动整理

桌面端现支持磁力链接与包含磁力的 Thunder 包装。用户先读取文件列表，再选择单集；未选择前只取得元数据，不下载整季。内置三个第一季片源的来源与 SHA-1 核对记录在 `app/cinema-sources/README.md`。已核对列表不代表公共节点当前在线，也不代表每个文件都有完整字幕。

## 组件与运行

维护者执行 `scripts/setup-cinema-runtime.ps1`（必要时传入 `-Proxy`）准备原生组件。aria2 1.37.0 来自项目官方 GitHub Release，下载 ZIP 与固定 SHA-256 比对；FFmpeg/FFprobe 取维护者已安装版本。运行时放在被 Git 忽略的 `runtime/cinema`，Windows 完整版构建会检查必要组件与许可文件，并复制整个 runtime。未创建新的公开安装包。

aria2 仅在明确下载操作时启动，RPC 绑定 loopback 随机端口、随机 token，不暴露给前端。原生子进程隐藏窗口，关联父进程生命周期；完成后 `seed-time=0` 停止做种，下载期间上传总速率限 16 KiB/s。未修改系统代理、迅雷设置或防火墙。

## 数据与状态

默认保存在学习数据库旁边的 `cinema-bt` 目录，可用 `WORDMASTER_CINEMA_DIR` 指定独立目录。每项 UUID 任务独立保存，原始下载在 `raw`，由 `index-out` 映射为短内部文件名（避免 Windows 长路径）；生成结果在 `ready`，不覆盖原始音轨和字幕。读写 API 限本机 Host，修改请求要求同源 Origin。种子 bencode、info hash、文件路径、数量和大小先校验；下载器参数不允许由用户任意传入。

状态：读取列表 → 选集 → 下载 → 校验 → 整理 → 可观看。关应用或暂停会保留文件；重开后主动继续。元数据预置仅用于减少查找等待，视频字节仍由节点提供。已完成媒体通过本地 HTTP Range 播放，字幕通过 JSON 接入现有播放器，无需把整集读进浏览器内存。

明确标注的英语音轨才会自动选用。提取英文和明确标注 Simplified/简中的文字字幕，按时间对齐；缺少音轨时报错，缺少字幕显示“需要补充字幕”，允许添加 UTF-8 双语 SRT。支持重听、查词和收藏。H.264/HEVC 原画面复制（HEVC 依赖系统解码），其他视频编码转为 H.264；图形字幕不做 OCR。

## 验证及限制

- 真实 aria2 下载本地 HTTP webseed 支持的 BT 测试资源，校验后 FFmpeg 提取英语与双语字幕，3 条字幕全部就绪。
- 实际用户磁力已做元数据和有限下载探测：校验码、8 集文件列表正确，测试窗口内未传输视频字节；未宣称三部剧已完成下载。另两部核对 12 / 7 集，未完整下载试听。
- 单元/接口测试覆盖元数据不自动下整季、选集、暂停/恢复、原件隔离、轮询与暂停竞态、损坏记录保留、同源检查、HTTP Range；浏览器验证原生下载结果重复打开、双语及句末暂停。
- 下载库与学习数据库分开；普通学习记录导出不含影片文件。用户删除影片须自行确认。
- 不实现网站登录、验证码绕过、付费链路、云加速。节点不可达会显示真实零连接状态，不能保证迅雷相同速度。
