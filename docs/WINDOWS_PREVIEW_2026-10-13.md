# Windows 发行候选包第一轮验收

日期：2026-10-13。状态：预览包，整轮优化尚未完成。

## 构建与启动

新增可编译的 `windows/WordMasterLauncher.cs` 和 `scripts/build-windows.ps1`。启动器只复用安装目录及数据库身份均匹配的墨词服务，不能把任意 HTTP 200 当作墨词。默认端口被占用时在 3456–3476 中选择空闲端口；服务隐藏运行，系统默认浏览器打开主界面。重复启动受安装级互斥保护，不并发初始化同一安装的词库。

发行目录采用白名单复制 app、shared、static、node_modules、runtime 和依赖清单；附带 Node 对应版本的 LICENSE。构建时拒绝带入数据库，发布清单记录每个文件的字节数和 SHA-256。不会包含当前学习记录、开发截图或离线审核文档。新安装首次生成个人数据库，升级需保留原 data 目录。

候选目录：`output/releases/WordMaster-2026-10-13-preview/`。压缩包：`output/releases/WordMaster-2026-10-13-preview.zip`。仓库根目录旧 WordMaster.exe 尚未覆盖；预览包不表示高考已上线。

## 已验证

使用 Windows 实际编译的 EXE，以 `--headless` 跳过打开默认浏览器；数据库路径为临时中文及空格路径。不是仅用 Node 直接启动来替代 EXE 验收。

- 首次初始化得到 26,268 词、schema 11、0 学习进度。
- 连续打开复用原服务，不重复启动。
- 同时双击的首次启动也复用同一服务；3456 上已有开发服务时选择 3457，不串用开发数据库。
- 首页、旅行入口、地图、营地、战斗、结局页面及相关只读 API 可访问。
- 当前真实数据库通过 SQLite 在线备份生成隔离副本，候选包启动和重开后，所有已有表的全部行哈希一致，完整性 ok，外键检查无异常。
- 实际用户数据库在验收前后完全一致；临时服务只在核对可执行文件路径后停止，不影响原开发服务。
- 全量自动测试 117 项通过，新增只读启动身份接口及其路径隔离检查。

ZIP 解压后的实际 EXE 已重复通过同样验收，765 个文件与哈希清单一致。最新单次观测：新库启动约 1.85 秒，重复启动约 0.23 秒，旧库副本启动及重开约 0.78–0.84 秒。不是五次重复性能基线，不据此宣称全站性能目标已完成。明细见 [机器验收记录](WINDOWS_RELEASE_CHECK_2026-10-13.json)。

验收发现并修复了两处问题：TCP 连接等待过短会将空闲端口误判为占用，改用本地绑定探测；验收脚本的 PowerShell 子进程需显式 UTF-8，避免中文路径比较误判。最终复测已通过。
