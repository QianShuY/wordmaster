# 电脑端英语训练

电脑墨词顶部的「英语训练」打开同一窗口的训练区（`/#/practice`）。返回训练时可接着当前试卷，离开训练区会暂停听力和计时。也可直接打开 `/practice/` 使用独立训练页。

两边顶栏共用 `/shared/desktop-shell.css`，包括尺寸、导航对齐、卡牌壁纸和数字字体。训练数据管理放在顶栏下方；试卷书架和训练记录与首页使用同一内容边距。替换词表前的旧词袋保留在词库页默认折叠的「历史资料」中。

## 训练生词

点击正文中的英文单词，选择「收进墨词词库」。单词也会留在训练生词本中；生词本支持批量收进墨词。未填写释义的旧条目会跳过并提示补充，保存失败可重试。批量请求同时按 200 条和 UTF-8 60 KB 分组，适应含长例句的大词本。

墨词首次收词时创建自建词袋「训练生词」。重复收取不会生成重复词条、覆盖已编辑释义或重置学习进度；不同试卷的来源会保留。收词不等于已经学会，不自动创建熟练度、复习期限或插入当前任务。需要学习时，在墨词选择此词袋开始学习。

训练自带词典缺词时先查询墨词的本地词库，再沿用原有后备查询。可提取的原文句子随词条保存，来源包含试卷与题型。

## 原独立版记录

浏览器按来源保存训练记录，原先 5174 等独立地址的记录不会自动出现在墨词端口。先在原训练页「数据管理 → 导出学习记录」，再在整合版「迁入原记录 → 导入原训练备份」选择 JSON。同名记录替换前仍需确认，原地址的数据不会被删除。电脑背词数据与训练成绩仍保持各自真实统计。

## 从源码构建

本仓库不提交整套生成媒体。保留训练源码仓库与其依赖，运行：

```powershell
.\runtime\node.exe scripts/build-english-training.js D:\cet6-practice
```

也可以设置当前进程的 `WORDMASTER_TRAINING_SOURCE`，或通过第一个参数传入训练源码目录。脚本执行生产构建，把包含离线音频和图片的产物放在 `static/practice/`。此目录在 Git 中忽略，Windows 打包脚本会随 `static/` 一起复制。未构建的安装目录显示明确提示并可返回墨词。
