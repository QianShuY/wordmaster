# 大地图：可行走的旅程手账

按旅行探索、画面布局、交互流畅度、沿途玩法的顺序调整。

## 本轮实现

- 桌面以一屏地图和右侧行程页为主体。原先地图下方的关卡说明与学习入口移入侧栏，拾笺和路线目录收在底栏。移动端保持完整地图，下方排列行程，不拖拽或横向滚动地图。
- 旅人停在真正抵达的上一关；已走过的道路、下一段可走道路和近处未达路段分别绘制。弯曲路线经过插画中的中间地形，不再直接用折线连接旗帜。
- 未知区域逐步揭雾，地图只显示已走过及近处路标。真实旅程未到第十三关时不展示最终 Boss 图标与终段路线。
- 已走过地点收为小印记，当前行程保留一面小旗；未知近路只留石标。区域标题随旅程推进改变。地图整体保留现有黄昏插画、纸色主题、轻水纹、炊烟、独立飞鸟和用户点击启用的配乐。
- 已解锁的五封线索也出现在对应路段上，点击打开信笺；远处线索不提前出现。目录和线索浮层可用 Escape 收起。
- 四段区域提供可选的 3～4 词小憩：低地辨义、河湾默写、古林辨义与默写交替、高地默写。词从真实已学池读取、每次不重复；误答可看答案后重试。同释义同词性的合格拼写和已有答案策略都被接受。
- 小挑战只在本地保存路印，按数据库实例区分。它不写日常学习记录、不推迟复习、不推进每日关卡、不颁发正式奖励。刷新前未完成的临时小挑战不保存；可以随时收起或换地点。
- 返回地图时默认沿用上一次实际通关用的词库，避免无故回到列表第一本词库。

## 性能处理

- 去掉水面动画中第二张整幅地图图像和持续运行的位移纹理，保留轻量水纹与瀑布线条。
- 地图不在视口、切换标签、手动停风或开启减少动态效果时暂停动画。
- 路标与目录用事件委托；路线预演拖动合并到下一绘制帧；悬停不重建地图。
- 自适应计算只读容器尺寸，地图全景等比显示。首帧先展开旅程，不闪现未解锁全图。

## 验证与界限

- 全套 337 项测试通过；合并网页版新增词库修订后，整合验证 351 项全部通过。补充地图路段、未知边界、真实旅人位置、预演隔离、四区小挑战配置，以及离开视口暂停测试。
- 1280×720 浏览器验收：桌面页面总高 720，无纵向页面滚动；地图和主要学习操作同屏。区域信笺、错误重试、三词挑战完成、路线预演到终点已实测。
- 小挑战使用独立实例、只读预览服务器验收，未操作真实通关或改动学习数据。正式地图仅查看与刷新。
- 本轮为客户端调整，刷新地图即可生效，无需重启正式服务。未重新打包 Windows ZIP。
- 当前仍是一张分层插画地图；没有声称实现 3D 地形、自由行走或 NPC 系统。
