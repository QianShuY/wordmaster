# 第一章正式结局与首通纪念

本轮完成正式挑战 → 战斗核对 → 首通落款 → 来信结局 → 纪念印章 → 重读入口。原计划的词库扩充、高考替换、全站性能和 Windows 发布仍需继续推进。

## 行为

- 沿真实旅程完成 13 个普通关卡，且到次日，才可创建正式挑战。路线预演显式进入练习，不创建正式记录。
- 服务端冻结本场已学词池、随机题序和初始状态；浏览器保留逐步操作手记。结算由服务端使用同一战斗规则重放，不接受前端直接上报胜利或生命值。
- 通关后点击“封存旅程 · 拆开来信”，保存首通结局与“渡雾者之印”。这是独立旅程纪念，不消耗或替代每日抽卡。
- 结算失败可保留手记重试；同场相同记录重复提交不重复发奖，改写已结算手记会被拒绝。
- 后续挑战不覆盖首次落款和战绩。来信、纪念收藏可从旅行首页和地图末关重看；已完成显示 14/14。
- 未通关时结局接口不返回剧情；既有动作预览不会解锁结局。

## 验证

- 全量 Node 测试：90 项通过，0 失败。
- 新测试覆盖未抵达门槛、非法操作、未胜利记录、首通、重复结算、第二次挑战、API 状态、迁移保留旧数据。
- 隔离数据库浏览器验收：正式开战，7 次正确默写获胜，刷新恢复，再封存进入结局；首通落款与印章显示成功。
- 1440px 双栏和 390px 单栏 DOM 尺寸检查均无横向溢出。截图接口两次无法捕获，因此尚未完成截图级视觉验收。
- 本地服务已重启到新代码，数据库升级至 schema 10。升级前后对 words、wordbooks、progress、review_log、recall_cycles、adventure_days、user_cards、card_draws、database identity、vocabulary builds 的全部行做 SHA256 比较，全部一致。32 条学习进度、84 条学习流水、现有 1 个旅程关卡均保持原样；完整性检查 ok，外键检查无异常。
- 正式库仅做只读 API 检查，没有代用户进行学习、抽卡、通关或解锁结局。隔离验收服务已停止。

## 实现范围与后续

挑战词池和初始题序保存在服务端；尚未结算的操作手记保存在当前浏览器。因此当前支持同浏览器刷新续接，尚不支持浏览器数据被清除后的战斗续接或跨设备续接。此版本通过规则重放判定合法胜负，不提供反作弊监控。

结局使用现有纸色、主题导航、信笺和印章样式；尚未增加独立结局插画或配乐。后续继续高考词库审核、跨日复习验收和全站性能优化。
