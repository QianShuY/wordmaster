# 跨日复习验收与再次遗忘修复

## 本轮结论

已完成隔离数据库中的跨日 API 回归。普通可拼写旧词在词义与拼写两步完成后才延长间隔；之后仍会再次到期。已巩固不等于永久掌握，连续答对次数不会使单词退出复习。

## 验收矩阵

| 场景 | 结果 |
| --- | --- |
| 23:58 完成词义，次日 00:02 接着拼写 | 词义状态保留；两步完成前不延长日期；完成后推进一级 |
| 未完成旧词回忆 | 今日任务仍包含到期词，未完成回忆阻止旅程通关 |
| 到期后的后续复习 | 按 1、2、4、7、15、30 天继续，达到 30 天后仍按 30 天安排 |
| 提前答对 | 不提前升阶，不延后原定复习日期 |
| 重复错误跨午夜、换会话恢复 | 错误次数保留；出错步骤要连续两次正确回忆 |
| 超期多天才复习 | 正常进入队列，不跳级；新日期从实际完成复习时算起 |
| 相同 request_id 再次提交 | 不重复计数，不再次延长日期 |
| 已完成轮次后再次答错且复用轮次 ID | 已修复：开启未完成的新回忆状态，恢复错误强化 |

## 修复的问题

原代码会因轮次 ID 相同而复用一个已完成回忆状态。若完成后再次答错，间隔虽然被重置为 10 分钟，状态却仍是“已完成”，后续正确回忆不能正常进入新的强化过程。

现在只复用尚未完成的回忆状态；完成后发生的新错误会建立新状态。原有重复正确提交保护保留：同轮重复答对不会重复延长间隔。再次遗忘后，词义和拼写重新完成，其中出错步骤需要连续两次正确回忆。

- 新回归先复现“已完成轮次再遗忘”的失败，修复后通过。

- 本轮不改数据库结构，不重置历史回忆、学习计划或学习日期。正式数据库受保护表全部行哈希一致，完整性 ok，外键检查无异常。

跨日结论来自模拟时钟下的 API 验证，未声称已进行数周真人学习。没有代用户提交真实答案、抽卡、通关。浏览器的每日任务检查点仍按日期失效；服务器保存的未完成回忆状态在新的每日任务中继续使用，不把昨天的新词配额搬到今天。
