# Boss 正式挑战：扩大单词考查范围

## 问题与实现

此前正式词池按最近复习顺序只截前 60 个词，普通回合答对一词即可施法。一场战斗实际抽查量很小，换一个预览词表无法解决正式挑战的考查不足。

新开的正式挑战与练习共用 version 3 规则：

- 词池上限 180：最多 60 个近期首次学习的词、额外最多 60 个易错词，其余名额从较早学过的词中按分布取样。仍只纳入有真实学习记录、可出题的内置词库词；历史只读词库、未学词、只放弃未学习的词不进入。
- 普通回合：半血前连续回忆 2 个不同词，半血后 3 词。墨矢/回春默写；护页先辨词义，再默写后续词。完整咒文完成才结算一次攻击与承伤。
- 残页领域：半血阶段 110 秒默写 6 个不同词；最后四分之一血量 140 秒默写 8 词。错答扣 6 秒，保留已完成封印；超时结算一次伤害。
- 抽词优先覆盖本场尚未考查的词。错误词仍隔开至少两次作答再强化；两次无提示正确默写后退出强化队列。每次施法内部不重复已答对词。
- 本场手记、结算显示实际考查过的不同词数。词池不足时按实际已学量抽查，不用未学词凑数。
- 新增抽取次数与本轮已完成词的存档字段，刷新保留普通连词与领域进度。正式挑战冻结词池，由服务端重放操作核验结局。

## 兼容与生效

version 1、2 的已开始战斗继续原规则，支持原手记结算；不把旧局中途加长。回营重开采用 version 3。正式服务需重新加载新共享引擎；静态页面刷新本身不会替换 Node 已加载模块。

本轮本地正式服务的自动重启被审批策略阻止，未停止原进程。用户正常关闭并重新打开墨词后加载新引擎；在此之前，运行中的正式服务仍沿用已加载的旧规则。

日常学习进度、复习日期、旅行解锁条件和章节结局不因战斗练习改变。未重新打包 Windows ZIP。

## 验证

- 100 词隔离词池、全对模拟：偏进攻配合治疗，11 回合 / 34 次作答 / 34 个不同词；全护页，16 回合 / 49 次作答 / 49 个不同词。数字是测试策略示例，非每场固定目标。
- 新增覆盖用例：普通连词与读档、完整战斗不提前循环、错词回插、6/8 词领域与倒计时、240 词候选中的近期/薄弱/旧词分布。
- 正式结局测试覆盖 version 1/2 旧局和 version 3 新局重放，以及伪造计时/提前作答拒绝。
- 全套 332 项测试通过；浏览器另用隔离词池核验 6 词领域 UI，未操作真实学习和正式奖励。
