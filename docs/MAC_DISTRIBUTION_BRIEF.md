# 墨词 macOS 朋友试用版：实施与验收要求

日期：2026-09-27  
状态：2026-09-28 用户将目标改为朋友的 iPad 第 10 代；本 macOS 方案暂缓。当前实施框架见 [IPADOS_10_PLAN.md](./IPADOS_10_PLAN.md)。

> 平台提醒：此文件只适用于 Mac 电脑上的 macOS 应用。朋友的 iPad 第 10 代需要单独的 iPadOS 版本，不能用本文件产出的 `.app`、ZIP 或 DMG 安装。不得把朋友的 iPad 试用当作 Mac 版验收。

## 目标

制作可发给朋友的离线 macOS 桌面应用。采用 Electron 复用现有页面、Express 业务接口和 SQLite。交付可解压/安装的 macOS 应用包及简短操作说明。这个版本是**未签名、未公证的私人测试版**：首次打开可能受到 macOS Gatekeeper 拦截，朋友需要手动允许；不能宣传为无提示直接安装的正式发布版。

优先做 Apple Silicon（M 系列）包；如朋友使用 Intel，改用相应架构或提供两个包。最终支持范围以实际 Mac 测试结果为准。无需 Apple Developer Program，也不需要向任何人索取证书或账号密码。

## 当前代码差距

- `app/db.js` 默认将 SQLite 写在项目 `data/wordmaster.db`。安装版需在加载该模块之前，将 `WORDMASTER_DB_PATH` 指向 Electron 用户数据目录下的独立文件；升级、重装不得覆盖已有数据库。
- `app/main.js` 固定监听 `3456`，没有把地址限定到回环接口。安装版应使用系统分配的空闲端口，仅监听 `127.0.0.1`，限制请求来源和写入接口访问，退出时关闭服务；避免第二实例或其他程序占用端口。
- `app/main.js` 加载时即打开 `node:sqlite`。先用实际 Electron 运行时验证兼容，确认初始化顺序、资源路径和只读安装目录行为。
- 当前词库“导入”只追加文本，不是完整数据备份。为朋友试用至少提供可恢复的版本化备份；覆盖自建词库、学习进度、日志、卡牌收藏和设置，并在导入失败时保留原数据。
- 打包只包含运行资源、词表、62 张本地生成插画和寄语；排除 `data/wordmaster.db`、`output/`、临时测试库、开发运行时及旧素材。卡牌科普和外链不得重新出现。

## 实施与验证

1. 建立 Electron 主进程、打包配置和单实例行为。在独立测试库上验证首次启动、学习一题、退出重开、记录保持、卡图、发音及完全离线使用。
2. 完成数据路径、服务生命周期、启动错误提示、窗口恢复和适合桌面的菜单；渲染进程关闭 Node 集成，启用上下文隔离与沙箱，限制导航和新窗口，设置 CSP。
3. 实现备份导出、导入预览、事务导入与回滚，测试升级安装不丢进度或收藏。保留现有 62 个卡牌 ID、抽卡规则与隐藏卡服务端过滤。
4. 在可用的 macOS 环境制作目标架构的测试包。没有自有 Mac 时，可使用受控的 macOS 构建环境；最终交由朋友的 Mac 验证，不能凭 Windows 上的构建结果宣称可用。
5. 交付包内附简明安装说明：先尝试正常打开；若被系统拦截，确认文件来源后按 Apple 官方步骤在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要要求朋友全局关闭 Gatekeeper 或执行清除隔离属性的终端命令。

## 验收门槛

- 朋友的目标 Mac 上能够打开；不要求安装 Node、Homebrew、Xcode 或数据库工具。记录 macOS 版本、芯片和首次启动结果。
- 内置词库、学习、默写、复习、统计与抽卡可离线使用；退出重开和覆盖安装后数据仍在。
- 备份能在干净用户账户恢复，自建词库、进度、日志及卡牌数量一致；损坏的备份不改变原库。
- 安装包不含开发者真实数据库、测试数据、科普外链或公网运行依赖；提供文件哈希和已知限制。
- 未经 Mac 实机安装和核心流程验证，只能称作“待测试构建”，不能称“已完成 macOS 安装版”。

本方案不涉及 Apple 签名与公证。若以后要对公众发布并减少系统警告，再另行增加正式发布流程。
