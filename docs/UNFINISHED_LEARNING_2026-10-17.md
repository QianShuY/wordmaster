# 已学单词与跨日未完成巩固

用户反馈：前一天到拼写时退出，第二天出现了不同的新词，无法找到学过的词。

## 原因和修复

本地断点按天过期；旧路径中的新词选择作答可能已把 next_due 推迟，但拼写尚未完成。次日既不属于新词、又尚未到期，因而没有进入原队列。数据库中的学习记录仍在。

新增 app/unfinished-learning.js，只读识别已经开始、但缺少巩固步骤的词，以及 recall_cycles 中尚未完成的回忆。今日任务优先以十词小组处理这些未完成词，即使其 next_due 尚未到期。已经完成词义与拼写的词不重复作为初学未完成词处理；正常到期复习仍有效。对没有明确学习模式的历史记录不盲目断言拼写未完成。

新词选择与拼写也使用既有服务端两步回忆机制，先完成词义及拼写再延长间隔。错误后的强化状态跨会话保留，不能靠重开页面或一次正确答案绕过。

首页增加“查看已学单词”和“未完成巩固 N 词”入口。词库列表增加已学、昨日学过、未完成巩固筛选，以及初学日期和未完成标记；未完成列表可直接进入接续学习。这个显式入口可绕过当前浏览器正在做的另一份今日断点，按数据库重新取出未完成词，先核对词义、再做拼写，不保证回到昨天退出时的同一个输入框或保留未提交的键入文字。

- 浏览器隔离夹具实际点击已学入口→筛选未完成→接续学习，确认回到 summon/pumpkin 两个未完成词，没有混入新的 bridge；真实数据库未参与浏览器操作。验收浏览器和服务已关闭。
