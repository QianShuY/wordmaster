# 墨词：电脑端优先迭代清单

> 产品方向：专业学习 × 轻游戏化。先把 Windows 本地网页 / EXE 的学习体验、记录可靠性和验收做扎实，再单独迁移到 Android。不要为了做动画改变复习算法。

## 电脑端（当前 PR）

### 已落代码
- 学习数据一致性下载备份：使用 SQLite `VACUUM INTO`，显示在「学习数据」页；备份文件需用户自己妥善保存，当前不提供自动云同步或一键合并恢复。
- 词库较小时，释义题优先选择本词库干扰项，不足四个时从其他词库补齐，且过滤重复释义。
- 学词接口校验 ID；桌面服务默认绑定本机，新增回归测试。
- 「今日」下方新增**学习旅程**：等级 / 墨点、最近七天答题量、日常十题抽卡进度和六枚成长印记。成绩从现有 `review_log` / `progress` / `user_cards` 只读计算，不创建额外状态，也不会由于重复提交而重复给墨点。
- 一轮默写 / 释义 / 词性结束后展示本轮获得墨点（首次答对 12，错后回炉答对 6），学词浏览不直接产生墨点。
- 电脑端词库管理采用独立分页搜索 API，中文释义/英文词头搜索、学习状态筛选、每页 40 条；避免一次性渲染超过万条单词。原 Android 词库接口保持不变。
- 今日页新增可选 10/20/40 词的短轮次，默认 20 词，到期复习优先；学习页新增专注模式及 Esc 退出快捷键。
- 改用事件委托处理包含引号的用户词库名、单词和错题，减少点击失败和意外解析风险。
- Android 暂不请求 `/api/desktop/journey`，且隐藏桌面专属组件。**本轮没有改 Android 原生存储、Bridge 或 APK。**

### 验收标准
1. 全新数据库及旧数据库都能启动，原词库、卡牌、进度与复习日期保持不变。
2. 从「今日」进入复习，答对 / 错后回炉 / 跳过均能正确保存；同一请求 ID 重试不重复计入墨点。
3. 电脑端首页首次学习为空态正常；有历史后等级、连学天数、近七天柱图和成长印记反映真实记录，不声称墨点会提高记忆效果。
4. 桌面版备份下载后经 SQLite `PRAGMA integrity_check` 检验有效；恢复流程需退出应用并保留回滚副本。
5. 自建词库不足四种释义时，选项不能重复，也不应该出现多个正确答案。
6. 在 1280px、1440px 及较窄的电脑浏览器窗口核对布局；键盘 Enter / A–D / 1–4、拼写输入、弹窗及滚动可用，检查深色/浅色系统设置下的对比度。
7. GitHub Actions `npm test` 和前端语法检查通过；**Windows EXE 的打包、原地升级、正式 GUI 试玩需独立实测**，自动测试通过不等于桌面版完全验收。

本地 Agent 验收操作、截图要求与反馈模板见 [LOCAL_AGENT_DESKTOP_ACCEPTANCE.md](LOCAL_AGENT_DESKTOP_ACCEPTANCE.md)。

## 电脑端后续优先级
1. **学习效率**：复习完成度更精确的提示；长词与词组拼写体验；更清楚地拆分「新词认识」和「成功回忆」；针对词义相似的干扰项质量抽样验证。
2. **学习体验**：桌面键盘操作、专注模式、长期词库的表格性能与批量导入易用性；首次启动引导和误操作恢复。
3. **数据可靠性**：增加图形界面备份恢复（先做文件验证、明确会覆盖、不允许运行时覆写）；桌面发行包升级流程以及 Windows 端验收。
4. **游戏性适度迭代**：印记挑战、成就提示和抽卡仪式感，避免奖励促使用户无意义重复刷题。

## Android 移植门槛（现在不启动）
只有电脑端主要交互、备份恢复、EXE 发行与真实 GUI 验收通过后，再单独开 Android 分支，先建立原生 SQLite 与桌面日志字段的映射，随后按 UI 验收清单迁移等级 / 印记等功能。Android 数据不与电脑端自动同步，不应误导用户认为两边记录已经合并。

## 设计边界
- 本地优先，不强制登录，不调用付费大模型 API。
- 游戏化基于已保存的真实记录，不能绕开风险控制与存储事务。
- 不在公开仓库上传任何真实用户数据库、秘钥、日志或含个人信息的导出文件。
