# 墨词 iPadOS 版实施框架（目标设备：iPad 第 10 代）

日期：2026-09-28  
状态：供用户交给实现 agent 的框架；用户选择真正的 iPad App、不公开上架 App Store。私下安装方式尚待选择；尚未委派、未实现、未在 iPad 实机验收。macOS 安装版暂不属于本阶段。

## 目标与边界

让朋友在 iPad 第 10 代上完成墨词的完整学习闭环：首次打开、内置词库、学词、拼写/选择/词性练习、保存进度、复习、统计、卡牌收藏；断网后仍可使用，关闭重开后数据保留。界面面向 iPad 竖屏和横屏设计，不把手机页面简单放大。

保持已有的 62 张本地生成卡图、卡牌 ID、稀有度与解锁规则；不恢复科普内容或外部链接。继续遵守 [词条与数据页视觉纠偏](./VOCAB_STATS_VISUAL_CORRECTION.md)：学词与拼写页面紧凑，拼写只有**一个可见输入区**，统计图表不制造误导性的趋势。

本阶段不做 Mac 安装包、Android 版本、云账号、跨设备实时同步、付费或商店正式上架。

## 架构要求

1. **页面复用，数据层重做。** 可使用 Capacitor 包装现有 HTML/CSS/JS，但 iPad 的 WKWebView 内不能依赖当前的 Express/`node:sqlite` 服务。先把前端 `/api/*` 调用整理为明确的业务接口；网页版继续接 Express，iPad 版接本机数据适配器。学习配额、复习间隔、抽卡条件与去重继续调用共享的纯规则，不复制两套相互漂移的算法。
2. **持久化。** iPad 端用可靠的本机 SQLite 方案存储词库、单词、进度、答题日志、卡牌与抽卡记录。选用插件或自建 Swift 桥接之前，记录许可证、维护状态、Capacitor/iPadOS 兼容性和实际构建结果。`localStorage` 仅可存非关键 UI 偏好，不承载学习记录。
3. **首装与迁移。** 把内置词库和卡牌清单作为只读种子资源随 App 打包，首次启动导入到用户数据库；后续更新只做版本化迁移，不覆盖用户进度、词库或收藏。不得把开发者电脑的 `data/wordmaster.db` 放入安装包。
4. **备份。** 实现版本化导出、选择文件导入、导入前摘要预览及事务回滚。至少覆盖自建词库/单词、进度、日志、收藏和设置；损坏或更高版本备份不改变当前数据。为将来从 Windows 版转移数据预留可验证格式。
5. **离线资源。** 字体采用已做的本地/系统回退，62 张 WebP、词表和中英寄语随包提供。发音优先使用设备可用语音能力，失败时练习可继续；首次学习和抽卡不得请求公网。

## iPad 界面要求

- 竖屏采用清楚的单列学习流；横屏可以是内容区与辅助进度区的受控双列，但内容宽度应有限制，避免 10.9 英寸屏上出现大面积空白。学习主操作在正常屏高与软键盘弹出后仍可到达。
- 学词卡显示干净词头、独立音标与朗读；多义项分组可读。拼写题只出现一个可见的输入区：点击字母格可聚焦真实输入控件，支持实体键盘、屏幕键盘、粘贴、删除、光标定位、词组空格/连字符/撇号。
- 卡册以图片为主；SR/UR 静态和交互效果可辨认，减少动态效果模式仍能识别等级和完成抽卡。锁定卡不泄露隐藏文案。
- 在 iPad 第 10 代实际验证竖屏、横屏、分屏尺寸、安全区域、系统字体放大、触摸目标、键盘遮挡、返回路径和 VoiceOver 基本阅读顺序。不要把浏览器模拟截图当作实机验收。

## 分阶段交付给审核者

### P0：可运行的本地数据样机

交付 iPadOS 工程、依赖与许可证清单、架构说明。用隔离测试库走通“首装 → 内置词库 → 学 1 词 → 拼写作答 → 退出重开 → 进度保留”；飞行模式重复。证明没有 Node/Express 常驻进程、没有公网运行依赖。

### P1：完整学习与卡牌

补齐四种学习模式、复习、错题、计划、统计、62 张卡与隐藏卡。验证保存失败可重试、不重复记答；每天抽卡最多一次，解锁条件与网页版一致。用同一份基准数据比较 Web/iPad 规则输出。

### P2：备份与 iPad 体验

完成导入/导出及回滚；处理屏幕方向、键盘、触摸、发音和减少动态效果。提交 iPad 第 10 代真实设备录屏、竖横屏截图、离线完整流程、数据库数量核对及安装方式说明。使用隔离数据库验证，生产库只读。

每阶段只在前一阶段审核通过后扩展，不以“能打开空壳”宣布完成。任何阶段若缺少 macOS/Xcode 或真机，仅能标为“代码完成、构建/实机未验收”。

## 给朋友安装的现实条件

| 路线 | 适用情况 | 限制 |
|---|---|---|
| 免费 Apple 账号 + Xcode 设备测试 | 开发阶段，iPad 能与一台 Mac 配对 | 设备测试凭证约 7 天到期，需要重新构建/安装；目前没有 Mac，不具备这条路线的执行环境。 |
| Apple Developer Program + Ad Hoc 设备直装 | 只给已登记的朋友 iPad 测试，不公开上架，也无需 TestFlight 测试审核 | 先取得该 iPad 的设备 ID（UDID），用开发者账号创建包含此设备的签名配置；在 macOS/Xcode 构建签名 IPA，朋友需通过 Xcode 或 Apple Configurator 等受支持流程安装。不能把任意未签名 IPA 发过去当 APK 安装。 |
| Apple Developer Program + TestFlight | 朋友在远处自行点邀请安装、反馈，不公开上架 App Store | 需要付费会员和可运行 Xcode 的 macOS 构建环境；外部测试首版需 Apple 测试审核；每个测试构建最长 90 天。 |
| iPad 浏览器/PWA | 暂不买会员但想先让朋友试用 | 是另一种交付形式，不能冒充 iPadOS 安装版；仍需实现本地离线数据层并部署可访问的初次安装入口。 |

**当前结论：**可以先完成 P0/P1 的代码与模拟器验证框架，但“把 iPad App 发给朋友安装”尚缺 macOS 构建环境、开发者账号以及 Ad Hoc/TestFlight 选择。两条路线都不要求公开上架 App Store，也都不能把未签名 IPA 直接发给朋友并声称可安装。不要让朋友提供 Apple 账号密码。

## 验收证据

- iPad 第 10 代的系统版本、竖横屏截图和真实设备录屏；安装来源、首次打开及飞行模式学习流程。
- 冷启动/退出重开/升级后的词库、进度、答题日志、卡牌 ID 与收藏数量；备份导入前后数量和损坏文件回滚证据。
- 数据保存失败、重复提交和重复抽卡的结果；软键盘、粘贴、实体键盘、VoiceOver、减少动态效果的操作记录。
- 新依赖的版本、许可证、打包体积、运行时外部网络请求列表；确保没有真实生产数据库和旧科普外链进入包。
