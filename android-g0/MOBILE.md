# 墨词 Android 随身手账 1.4.6

这是可脱离电脑使用的 Android 离线测试版。支持 Android 7.0 及以上，建议使用较新的 Android System WebView。首次安装已包含五本词库共 27,666 个词及对应双语例句；内容覆盖不代表逐条人工审校完成。

## 安装与已有记录

将 APK 发到手机后，允许文件应用安装此测试包。此包使用开发调试签名，不是应用商店正式发布包。旧版使用相同包名且签名一致时可覆盖安装；如果提示签名冲突，请先备份旧版，勿直接卸载丢失记录。

1. 电脑根目录运行 `Export-To-Mobile.cmd`，在 `output/mobile-transfer/` 得到迁移 JSON。导出以只读方式打开电脑数据库，不会修改学习记录。
2. 将 JSON 发到手机，在「我的 → 恢复或导入电脑记录」选择文件，核对后确认。
3. 导入会替换手机学习记录、学习断点及收藏；先导出手机备份。电脑自建词袋一并迁入，历史中考资料保留为归档，不跨词书合并熟练度。
4. 未完成巩固会拆成每组最多 10 词继续。电脑浏览器尚未提交的输入草稿不属于数据库记录，无法迁移。

电脑与手机当前通过文件迁移，**没有云端自动同步，也没有手机到电脑的反向导入**。卸载前务必在「我的 → 导出手机备份」保存文件到应用外。

## 1.4.6 统一桌面与手机的手账风格

- 手机首页、学习页和底部导航采用与电脑端一致的墨词标志、纸色和选中样式。学习页与专属字母键盘跟随手账主题配色。
- 在「卡牌」打开已收藏的卡牌，轻触「设为手账主题」。配色与电脑端共用，在手机本机保存。可在「我的 → 手账主题」恢复经典纸色。
- 版本号 1.4.6，versionCode 17。测试 APK 与 1.4.5 的包名和签名一致。主题切换、恢复和拼写续接已在浏览器预览验收，真机显示与触控待复核。

## 1.4.5 Android 触摸兼容修复

- 为手指输入增加捕获阶段的 Touch Events 通道；横向锁定后由非被动 touchmove 阻止原生滚动抢走手势。忽略重复的触摸 Pointer Events，防止兼容事件重复切页，也避免 pointercancel 取消 Touch 通道中的滑动。
- 缩短水平识别距离，并放宽轻微斜滑的容差；垂直方向仍交给原生滚动。多指操作、系统取消、输入框、横向筛选栏、地图及字母键盘不触发主栏目切换。
- 新增触摸事件回归，覆盖五栏目的左右方向、Pointer 取消与 Touch 并存、原生滚动、多指和取消。旧版代码在新增触摸测试中失败，修正版通过。浏览器已检查拖动切页与返回，但浏览器鼠标验证不代表 Android 真机触控验收；目前无连接设备，仍需手机确认。
- 同包名、同签名，versionCode 16；覆盖安装后「我的 → 关于这本手账」显示 1.4.5。不要卸载旧版。

## 1.4.4 主栏目左右滑动

- 今日、词袋、旅行、留影、我的支持按底部顺序左右滑动，不循环。水平拖动跟随手指，短拖、取消和边界拖动回弹；距离或快速轻扫达到阈值才切换。点击底部栏目使用相同方向的短距离滑入。
- 主栏目手势和导航统一驱动独立的 app 位移，不复制旧画面；取消另一层主栏目淡入。新内容准备好后清除拖动位置并滑入，防止滑动期间出现空白等待。
- 竖向滚动、输入框、系统弹层、地图拖动区域、字母键盘、学习及战斗页不参与栏目手势。旅行页可在标题、工具栏、行程或底部导航处换栏目。滑动后的合成点击被拦截，避免触发原页面按钮。
- 446 项回归通过，新增顺序／边界、速度与距离阈值、跟手位移、竖向取消、地图／输入／弹层排除等检查。浏览器实际左滑今日至词袋、右滑返回；APK 和原生测试 APK 构建通过。没有连接真机，触屏手感和系统边缘手势需手机验收。

## 1.4.3 撤回重叠转场，减少切题跳动

- 删除旧页面克隆、固定叠层、尺寸测量、逐题横移和逐题淡入。同页题面、筛选及战斗状态更新立即呈现；切页仅保留 110ms 的轻微透明度恢复，不从空白淡入，不移动内容。
- 主题、导航、焦点页面样式和滚动复位与新内容一起更新，避免数据加载期间旧页先变色、被隐藏导航或提前滚动。键盘随屏幕更新只同步一次，撤去额外的 DOM 观察同步与逐页重复同步。
- 弹层只做 100ms 轻微透明度恢复，关闭立即生效；移除遮罩单独进场动画。支持减少动态效果，后台取消残留动画。
- 441 项回归通过；最终键盘同步调整后又通过 16 项输入、战斗提交与转场检查。APK 和原生测试 APK 构建通过。浏览器可核对交互，真机帧率与触控流畅度未测量。

## 本版功能

- 今日任务、五库切换、每组最多 10 词的认识／词义回忆／拼写；错词留在小组内继续巩固。
- 按到期量分批安排复习、积压时减少新词；同一天已完成任务不会自动再塞一整轮。
- 保存学习阶段、答题反馈及拼写草稿，返回后继续原题；交易失败不算完成，重复请求不重复计数。
- 已学词／错词搜索、学习足迹、收藏留影与抽取。
- SQLite 本地存储、带校验的备份恢复、电脑记录导入。旧 Android 数据库另存保留，一次性迁入新版数据库。
- 旅行配乐、三阶段战斗音乐、打击音效和结局配乐均随 APK 打包，使用媒体音量，不依赖 TTS；进入地图轻触右上角配乐按钮播放。战斗血量变化会切换音乐，旧曲先暂停，不叠播；离开页面或切后台暂停。单词读音使用 Android 系统 TTS，优先离线英语声音，也兼容引擎提供的其他英语声音。若无可用声音，可在「我的 → 系统英语发音」选择引擎、下载英语语音；引擎自身的联网能力取决于系统设置。应用本身没有网络权限。

旅行页已接入本地地图、初次来信、每日行程与五封沿途线索。完成当天的整份词义与拼写计划后，可领取一程，每日最多一程；到第十三程抵达雾桥后开放正式 Boss 挑战。正式战从本机已学词中选取最多 80 个不同的可拼写词，至少需十词。战斗使用与桌面相同的连续回忆、破盾、护页、回春、誓言重燃与残页领域规则，6／8 个词的限时默写有错答扣时；胜利后写入第十四程并展示章节结局。手机旅行进度暂不与电脑互通。

## 构建

使用 Node.js 24、JDK 21、Android SDK 36。在仓库根目录先 `npm ci`；再进入 `android-g0` 执行 `npm ci` 和 `npm run android:sync`，它会从当前桌面源码生成独立的干净种子库，不读取个人学习库。

进入 `android-g0/android` 执行 `gradlew :app:assembleDebug :app:assembleDebugAndroidTest`。Windows 中文路径若导致 wrapper 脚本乱码，可用 PowerShell：

```powershell
& "$env:JAVA_HOME/bin/java.exe" -classpath ./gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain :app:assembleDebug :app:assembleDebugAndroidTest
```

输出 `android-g0/android/app/build/outputs/apk/debug/app-debug.apk`。`npm test` 在仓库根目录执行，会先生成手机测试种子库，随后运行桌面与手机服务测试。旧 G0/G1/G2 源码与锁表保留作回归资料；旧 `build:web` 不会构建当前手机版，请使用 `android:sync`。
