# 墨词 Android G2 离线测试包

## 安装

1. 将同目录的 `app-debug.apk` 复制到安卓手机。
2. 在手机“文件/下载”中点开 APK，按系统提示安装。
3. 如遇系统拦截，只允许当前文件管理器或传输来源“安装未知应用”，返回后继续安装。
4. 打开“墨词 Android 本地版”。最低要求 Android 7.0（API 24）。

如果手机已装 G0/G1/G2 测试版，可直接覆盖更新，不要先卸载；版本是 `1.2.1-g2`，包名保持 `io.wordmaster.g0prototype`，升级会保留本地学习记录。

## 已包含

- 今日页与 5 本内置词库（20,374 词）
- 学词、拼写默写、释义选择、词性判断
- 学习计划、错题回炉、学习统计
- 62 张卡牌、离线卡图、抽卡与解锁
- 自建词库、词条编辑与批量导入
- 本地 SQLite 存储，不连接电脑服务

## 本版手机体验调整

- 学词卡片居中；可上滑看释义，再左右滑选择是否学会。
- 拼写题会自动聚焦英文输入区，点“不会，看答案”等按钮一次即可执行并收起键盘。
- 抽卡入口更醒目；学习统计热力图打开后显示最近日期。

这是 debug 测试包，不是正式发布包。卸载会删除本机数据；正式发布签名和商店工作尚未开始。
