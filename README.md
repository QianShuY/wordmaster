## 功能

- **四种学习模式**（先学后测：学词→默写闭环）
  - 学词：翻卡浏览新词（单词/音标/发音 → 点卡翻面看释义例句），"还不太熟"的本轮重看；学过的词立即进入默写队列
  - 拼写默写：看释义+词性，逐字母默写单词，即时对错反馈；光标可用 ← → 自由移动、点击格子定位
  - 释义选择：看单词，四选一中文释义；自建词库不满 4 种释义时从其他词库补充干扰项，避免重复选项（全库不足 4 种时仅展示实际可用项）
  - 词性判断：看单词和释义，选出正确词性
- **学习计划**：为词库设定目标学完日期，系统按「剩余新词 ÷ 剩余天数」自动分配每日新词量；复习按艾宾浩斯遗忘曲线（1→2→4→7→15→30 天）自动安排，答错 10 分钟后立即重学并加入本轮回炉
- **学习数据**：独立统计页——连续学习天数、今日待复习/新词进度、近 30 天学习量柱状图、12 周热力图、正确率走势折线
- **卡牌收集**：每天完成学习（≥10 次作答）可抽一张卡牌；59 张普通卡与 3 张隐藏卡均使用项目内生成的原创插画，分 N/R/SR/UR 稀有度；集满 10/20/30 张依次解锁隐藏卡
- **错题本**：答错的单词自动收集，连续答对 3 次自动移出；可单独回炉练习或手动移除
- **词库管理**：内置中考、四级、六级、考研、专四专八五种词表（实际收录与待核验范围见审计报告）；可新建词库，单个添加或批量导入单词
- **学习统计**：今日已学、已掌握数、总正确率，各词库掌握进度环
- 单词发音（浏览器 TTS）

## 电脑端「专业学习 × 轻游戏化」升级

「今日」首页新增桌面专属学习旅程：**墨点 XP 等级、最近七天真实学习记录、每日十题进度与六枚成长印记**；完成一轮测验后可看到本轮赚取的墨点。首次答对记 12 墨点，错后回炉答对记 6 墨点，答错或放弃不加分。墨点由已有答题流水动态计算，无需迁移数据库；重复请求不会重复计算，等级只反映学习投入，**不影响遗忘曲线与复习安排**。

电脑端还新增**专注模式**（背词时隐藏导航与装饰，Esc 退出）和**大词库管理的每页 40 词分页、搜索英文/中文释义和学习状态筛选**。独立训练入口保留短轮次设置，但「今日」学习任务不再受 10/20/40 题的任意上限限制。这几项不会强迫调整遗忘曲线；原 Android 词库 API 保留不变。

功能目前仅供**电脑端**使用，Android 暂时沿用现有页面与独立存储，不会自动同步电脑的学习进度。电脑端设计清单见 [docs/DESKTOP_FIRST_PLAN.md](docs/DESKTOP_FIRST_PLAN.md)；本地 Agent 的拉取命令与逐项验收标准见 [docs/LOCAL_AGENT_DESKTOP_ACCEPTANCE.md](docs/LOCAL_AGENT_DESKTOP_ACCEPTANCE.md)。

## V1.2 电脑端 · 学习中枢与学习计划重设计

这版将电脑端「今日」整理成统一的 **学习中枢**：

- **左侧「长期方向」**：主视觉展示当前词库、长期目标、剩余新词、目标剩余天数、每日新词安排，以及新词学习覆盖率。覆盖率只代表“开始学习过的比例”，**不等于已掌握比例**。
- **右侧「当下任务」**：一眼看清「到期复习 + 今日新词 = 完整今日任务」，不再出现 13 个待复习却只让学 10 词的矛盾。点击开始，按复习 → 新词 → 默写巩固的步骤完成，同一流程中在阶段完成页继续下一步；错题回炉是独立入口。
- **完整学习计划工作台**：从今日页点击「制定/调整学习计划」，在宽屏双栏面板里选择日期，实时预览每日新词数量和计划强度。遇到超出每日 200 新词上限的日期，明确提示调整，而不是暗示不可能的进度也能完成。
- **词库页只负责资料管理**：电脑端隐藏卡片上的重复学习计划入口，仍保留 Android 原有计划入口。
- **学习与统计页**：电脑端统一控制栏、单词主次操作、统计数值层级及无数据时的提示。

电脑端新样式放在 `static/desktop-redesign.css`，方便独立验收和回退；Android 独立版仍使用之前的首页与计划弹窗，不动原生 Bridge、SQLite 存储或 APK。本版本无云端同步。

本地 Agent 的分支拉取与验收步骤见 [电脑端验收任务书](docs/LOCAL_AGENT_DESKTOP_ACCEPTANCE.md)。**自动化通过不代表 Windows / EXE 真实交互已经测试完成**。

## V1.3 · 今日任务与统计口径统一

- 当前词库若有 **13 个到期复习和 10 个今日新词**，首页显示 **23 个今日任务**。点击后先完成 13 个复习，再点击继续新词，学完后可巩固默写；两部分属于同一套今日计划，而不是让用户再次选择 10/20/40 的单轮上限。复习超过 200 或新词超过单次后端限制时，完成后可继续剩余任务，不隐瞒待办。
- 学习数据页默认查看**主页选中的词库**；可切换至「全部词库」。在全库视图只汇总实际作答、待复习、新学词数，不再把各词库的日配额直接相加成误导性的 `0/255`。
- 修复正确率百分比的字号，统一统计卡片里的数字字体。Android 保留原接口和页面，不接受本次 UI 变更。

## V1.4 · 电脑端完整学习旅程（待本地 GUI 验收）

「今日」现在是一条贯通的学习流程：**到期复习 → 计划内新词 → 巩固默写**。学词界面增加三阶段标记和本日任务整体进度（新词默写是巩固环节，不会虚增“今日任务词数”）。完成每个阶段后，结算页面分别呈现真实答对/回炉/错误，或者新词认识与回看数量，并提供明确的“继续下一阶段”按钮。

学习过程中可以点击**「保存进度并退出」**。电脑端会在**已成功提交的答题/学词记录**之后保存同日断点，下次从当前题目或最近的阶段结算处继续；主页显示断点提示。SQLite 始终是学习成绩、错题与复习到期日的权威数据源，浏览器断点只负责恢复题目顺序，**不是数据库备份或跨设备同步**。断点绑定当前数据库实例与当天日期，避免正式数据库与临时测试库串题；跨天失效，重新按真实数据库生成任务。

注意：网络请求尚处于“正在保存”状态时请等待确认再退出；关闭浏览器若禁用本地存储或空间不足，断点可能无法保存。安卓独立版的学习逻辑、界面和数据库尚未迁移 V1.4。完整验收步骤见 [本地 Agent 任务单](docs/LOCAL_AGENT_DESKTOP_ACCEPTANCE.md)。

## V1.5 第一轮 · 学习诊断与复习建议（电脑端开发中）

学习数据页新增轻量「学习诊断」，从本机 SQLite 真实记录计算：

- **最近 7 天作答正确率**与前一个 7 天的对比，标注真实作答次数；缺少样本显示「—」，不会伪造 0%。
- **新词学习覆盖率**和**真正已掌握数**分别展示；覆盖只说明开始过，不代表熟练掌握。
- **优先关注的单词**按到期复习优先，再看有错题记录的单词，每个词都说明推荐理由。
- **行动建议**只做清晰的任务优先级排序：到期复习 > 回看错词 > 新词学习。现有间隔复习和每日计划算法不变。

电脑端新只读接口：`GET /api/desktop/insights` 或 `GET /api/desktop/insights?book_id=:id`。不调用付费模型，不新增用户记录，也不改 Android 的 API 或界面。

**此功能暂在独立 V1.5 草稿 PR 开发**，以 V1.4 修复分支为基础；V1.4 的实际 GUI 复测仍是发布门槛。详细指标定义及 Windows Agent 验收步骤见 [V1.5 学习诊断验收计划](docs/V1_5_LEARNING_INSIGHTS_ACCEPTANCE.md)。

## V1.5 第二轮 · 重点词直达与按词库回炉

电脑端「建议关注的单词」现在能直接指向后续操作：**已到期词**会进入其所属词库的完整今日复习，**尚未到期但曾答错的词**则跳转到所属词库错题本并高亮对应单词。新错题筛选器支持查看某一本词库或全部词库，回炉练习和结束后的「再来一轮」均保留选择范围。

这避免了“诊断显示 A 词库，却跳到全库错题”的职责混乱。建议仍然是只读分析，只有明确点击回炉练习并作答后，才会按现有流程更新 SQLite 复习记录。新增 `GET /api/mistakes?book_id=:id` 和 `GET /api/mistakes/study?mode=...&book_id=:id` 作为**可选筛选参数**；省略参数的原接口保留给 Android。

完整 Windows 验收清单见 [V1.5 学习诊断与直达验收计划](docs/V1_5_LEARNING_INSIGHTS_ACCEPTANCE.md)。本 PR 仍是基于 V1.4 的草稿，未合并 main、未完成 Windows GUI 复测。

## V1.5 第三轮 · 回炉后反馈（电脑端）

从错题本完成一轮练习后，结算页会根据 SQLite 实际记录重新显示**当前范围仍需回炉的词数**，区分「本轮答对」和「已达到掌握条件」。如仍有错题，可以一键继续同一本词库的回炉练习；若当前范围没有错题，就返回错题本查看结果。查询失败时会解释无法确认剩余数量，不会伪报 0。

本轮还处理了新手引导与错题训练互相污染、连续开始新一轮时旧请求覆盖页面的风险。桌面端新增结算展示，但**既有 streak / 复习间隔与 Android 独立版不变**。新增真实 `/api/progress` 回归测试确认一次答对不能误判为已掌握、不同词库互不串数。

当前依然是 V1.5 **草稿 PR #2**，实际 Windows GUI 验收任务和失败场景见 [V1.5 验收计划](docs/V1_5_LEARNING_INSIGHTS_ACCEPTANCE.md)。正式版未重新打包，必须在本地切换到 V1.5 分支运行源码才能看到更新。

## V1.5 第四轮 · 学习诊断与今日任务一致性

诊断页对**词库长期未学数**与**今日还可学的词数**做了区分。只有本日配额内可学的新词才会触发「今日继续学 N 词」建议；如果今天已完成配额，即使词库仍有未开始的词，也会明确写「今天没有需要继续的新词任务」。与 `/api/desktop/books/:id/today` 使用相同计划计算式并通过 API 回归测试比对。

电脑端空历史累计正确率显示「—」，而不是误导性的 `0%`。顶部改标为「全库累计正确率」，统计页可查看当前词库的累计正确率，且两种范围均不受这次文案改动影响。统计页快速切换和重新进入时也会忽略旧页面尚未返回的词库列表请求。

这轮变更仅限电脑端的诊断和数字展示，Android 保持现有接口及 UI。具体手工验收步骤参见 [V1.5 Agent 验收清单](docs/V1_5_LEARNING_INSIGHTS_ACCEPTANCE.md)。

## 学习数据备份（桌面版）

学习记录保存在本机 SQLite 数据库中，并不会自动同步到其他设备。建议定期备份，尤其是在升级或更换电脑之前。

1. 打开「学习数据」页面，点击「↓ 备份学习数据」，保存下载的 `WordMaster-backup-YYYY-MM-DD.db`。
2. 备份使用 SQLite 一致性快照（`VACUUM INTO`），不用停止学习服务器，也不会清空原始数据。
3. **恢复前先完全退出墨词**，并额外复制一份当前的 `data/wordmaster.db` 备用；把下载的备份文件改名为 `wordmaster.db`，替换原数据库，再启动软件即可。恢复会**覆盖**当前的学习记录、词库和卡牌，无法自动合并。
4. 若使用 `WORDMASTER_DB_PATH` 自定义数据库位置，备份和恢复都应针对该文件；不要在程序运行时直接复制正在使用的 `.db` 文件。

这个入口仅供**桌面/本机网页版**使用，Android 独立版使用另一套本地存储，**不包含在此备份内**。为保护学习记录，桌面服务器默认只监听 `127.0.0.1`，如确需局域网访问，可自行设置 `WORDMASTER_HOST`；备份接口仍只接受本机请求。数据库文件可能包含个人学习记录，不要把实际使用的数据库提交到公开仓库。

## 启动

**免安装版（推荐发给别人）**：解压后双击 `start.bat`，无需安装任何环境（内置 Node 运行时和依赖）。

**开发版**：需要 Node.js ≥ 22.5（使用内置 `node:sqlite`）。

```bash
npm install   # 首次
npm start     # 或双击 start.bat
```

打开 http://localhost:3456

## 结构

```
app/main.js       Express 服务，REST API + 静态文件
app/db.js         SQLite 建表 + 内置词库种子
app/seed/         词表原始数据（来源：github.com/mahavivo/english-wordlists）
static/           前端单页应用（原生 HTML/CSS/JS）
static/cards/original/  62 张生成的原创卡牌插画（WebP）
data/             wordmaster.db（首次启动自动生成）
```
